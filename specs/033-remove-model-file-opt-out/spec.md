# 기능 명세: 모델 파일 사용 해제 옵션 제거

작성일: 2026-11-08
상태: 명확화 완료
입력: GlueModelEditor 설정에서 No use .glue_uml_ad file 옵션을 제거하고 항상 false로 처리한다.

## 사용자 시나리오와 검증

### 사용자 이야기 1: 모델 파일 사용으로 고정 (P1)

설정 화면에 해당 체크박스가 없어야 한다. 과거 프로젝트 설정에 true가 저장돼 있어도 false로 읽고 저장한다. Service 열기는 기존 false 모드와 동일하게 모델 파일을 찾으며 서비스 XML 직접 Design 모드는 활성화되지 않는다.

## 요구사항

- FR-001: GlueModelEditor 설정에서 해당 체크박스와 초안 로드·적용 연결을 제거한다.
- FR-002: 과거 true 상태를 로드해도 유효 설정은 항상 false다. 기존 XML 호환 필드는 남길 수 있으나 다시 저장할 상태는 false이며 외부 상태 사본 변경으로 활성화할 수 없다.
- FR-003: 기존 false 모드의 .glue_uml_ad 열기·Service 찾기·모델 저장 시 서비스 내보내기 동작을 유지한다. 서비스 XML 직접 편집 모드의 provider는 선택되지 않는다.
- FR-004: Service 저장 경로·Activity preset·색상 등의 다른 설정과 Apply·Reset·직렬화는 유지한다. 과거 true 모드 전용 UI 검증은 새 동작으로 교체하고 내부 서비스 어댑터 회귀는 유지한다.

## 주요 개체

- 저장 상태: 이전 noUseGlueUmlAdFile 필드의 호환 입력과 정규화된 false 값.
- 설정 초안: Service 저장 경로·preset·색상만 편집한다.

## 성공 기준

- SC-001: 체크박스 부재·true 설정 마이그레이션·재저장·설정 수명 회귀가 통과한다.
- SC-002: 모델 파일 선택·서비스 provider 제외·일반 내보내기와 기존 모델 편집 회귀가 통과한다.
- SC-003: 전체 테스트·설치 ZIP·플러그인 구조 검사가 통과한다.

## 가정과 명확화

질문 0개. 후속 지시의 ‘세팅에서 제거’는 체크박스 삭제 위치를 명확히 한 것이며 앞선 항상 false 동작도 유지한다. 과거 서비스 XML 직접 편집 UI는 이 설정이 true일 때만 제공되던 동작으로 더 이상 활성화하지 않는다. 서비스 파일이나 모델 파일을 삭제하거나 변환하지 않는다.
