# 조사 결과

- 옵션은 ModelEditorState에 저장되고 설정 패널이 true/false 초안을 편집한다. loadState에서 정규화하면 모든 기존 소비자가 false를 보게 된다.
- true 상태는 서비스 XML 직접 Design provider와 Service 파일 선택 및 모델 저장 내보내기 분기를 바꾼다. UI만 숨기면 과거 true가 계속 동작하므로 저장 상태 정규화가 필요하다.
- 과거 직접 서비스 UI 테스트는 더 이상 사용자에게 제공하지 않는 모드에 의존한다. 해당 전용 시나리오는 폐기 후 계약으로 교체하고 일반 모델 UI·서비스 어댑터의 독립 검증은 남긴다. 미해결 기술 질문은 없다.
