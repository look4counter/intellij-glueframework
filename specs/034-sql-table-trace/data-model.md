# 개체와 관계

- CTE 정의: 이름·이름 토큰 위치·선언 컬럼·쿼리. 같은 문자열이어도 객체가 다르면 독립이다.
- 소스 참조: 이름 경로 토큰·별칭 토큰·시작 위치·CTE 또는 파생 쿼리. 물리 소스는 해당 사용 인스턴스에만 속한다.
- 테이블 노드: 표시 위치·직접 입력 집합·직접 소비자 집합. CTE 참조는 정의를 입력으로 연결하고 파생 테이블은 내부 쿼리의 직접 소스를 입력으로 연결한다. UNION은 각 분기를 입력으로 연결한다.
- 선택: 선언/참조 토큰 또는 유일하게 해석된 한정자로 노드를 선택한다. CTE 참조 선택은 공유된 정의를 기준으로 삼는다.
- 결과: 선택의 상위 원본 집합과 원본의 하위 소비자 집합을 구한 후 입력을 소비자보다 먼저 출력한다. 한 줄에 여러 참조가 있으면 첫 표시 위치를 유지하고 줄은 중복 제거한다.

분석 상태는 요청 수명에 한정된다. 순환 및 방문 집합·길이/깊이/작업 한도·취소 확인으로 중단 가능하다. 문서의 최신 stamp와 요청 세대가 일치할 때만 UI에 적용한다.
