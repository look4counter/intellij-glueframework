# 테이블·컬럼 추적 트리 UI 계약

- 테이블명·CTE 선언/참조·파생 테이블 별칭·`별칭.컬럼`의 별칭에서 기존 TRACE 목록을 갱신한다.
- 컬럼에서 선택하면 기존 컬럼 분석을 수행한다. 테이블 경로는 DB 연결 없이 SQL 구조에서만 계산한다.
- query.trace.tree는 IntelliJ 표준 Tree다. 숨긴 가상 루트 아래 원본을 표시하고 직접 소비자를 자식으로 표시한다. 각 항목은 식별자·줄 번호·SQL 내용과 정확한 이동 위치를 가진다. 같은 줄의 별개 객체는 합치지 않는다.
- 왼쪽 마우스를 누르는 시점과 Enter에서 표시한 토큰으로 이동하고 해당 행을 선택한다. 누름 후 조금 움직여 클릭 이벤트가 생략돼도 이동한다. 목록 이동 중에는 경로를 유지하고 문서를 수정하지 않는다.
- 빈 목록 문구는 `추적할 컬럼이나 테이블에 커서를 놓으세요.` 하나다. 세로 가운데·좌우 8 논리 픽셀 패딩·제목/하단 상태 문구 없는 구성을 유지한다.
- 편집·쿼리 전환·커서 변경·해제 뒤 이전 요청 결과를 표시하지 않는다. 주석/문자열/한도 초과에는 잘못된 경로를 만들지 않는다.
- 그래프의 선택 정점 ID를 우선 사용해 현재 노드를 선택한다. 한정자·별칭은 대응 소스 참조 위치를 사용한다. 표시 단계가 없는 조건절에서는 무관한 노드를 선택하지 않는다.
- 자동 선택 행은 보이도록 스크롤한다. 빈 영역·왼쪽 이외의 버튼·오래된 결과로는 이동하지 않는다.
- 펼침 화살표·좌우 키와 기본 더블 클릭은 표준 접기·펼치기를 수행한다. 화살표 누름은 SQL을 이동시키지 않는다. 본문 누름은 트리 포커스를 유지하고 Enter는 해당 위치의 편집기로 이동한다.
- 공유 정점은 각 실제 경로 아래에 나타난다. 현재 경로 안에서 순환을 발견하면 순환 참조 표식을 붙여 종료한다. 2048개 표시 노드 또는 깊이 96 한도를 넘으면 한도 표식을 표시한다.
- 최초 경로는 펼쳐 보여준다. 같은 문서·stamp의 접힘 상태는 보존하고 현재 노드의 필요한 조상만 펼친다. 편집과 쿼리 전환은 화면 상태를 초기화한다.
