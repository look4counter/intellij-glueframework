# TRACE 화면 계약

- 위치: Query Design 우측 패널 하단. 제목 라벨은 표시하지 않으며 목록 이름은 `query.trace.list`다.
- 형식: `2: SELECT SS`처럼 실제 줄 번호와 줄 내용을 표시한다. 커서가 중간 단계에 있어도 원본부터 마지막 사용처까지 표시한다.
- 여백: 쿼리 목록과 동일하게 항목의 좌우에 각각 배율이 적용된 8 논리 픽셀 패딩을 둔다.
- 빈 상태: 목록 내부의 세로 가운데에 `추적할 컬럼에 커서를 놓으세요.`만 표시한다. 초기·분석 중·출처 불명 등 상태에 따라 문구를 바꾸지 않는다. 목록 아래 상태 라벨과 오류 툴팁은 표시하지 않는다.
- 대상: SELECT 출력과 CTE·파생 테이블의 전달 단계만 표시한다. 조건·조인·그룹·정렬 절에서 컬럼을 선택해도 해당 컬럼의 출력 경로만 보여준다. 조건 서브쿼리 자체의 컬럼과 출력 전달 경로가 없는 컬럼은 빈 목록으로 표시한다.
- 이동: 마우스 한 번 클릭 또는 Enter. SQL 내용·선택 쿼리·Source를 변경하지 않고 컬럼 위치로 이동한다.
- 갱신: 일반 커서 이동과 문서·쿼리 변경에 반응한다. 목록 자체의 탐색은 표시된 경로를 유지한다. 변경된 문서의 예전 항목은 실행하지 않는다.
