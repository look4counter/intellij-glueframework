# 데이터 모델

- 추적 항목: SQL 문서의 1 기반 줄 번호, 해당 줄의 표시 문자열, 컬럼 오프셋. 같은 오프셋은 한 번 표시한다.
- 추적 결과: 항목 목록, 내부 분석용 선택적 설명. 불확실한 원인은 결과에 보관하되 화면과 툴팁에는 표시하지 않고 빈 목록의 고정 안내만 사용한다.
- 내부 출력 슬롯: 출력 이름, 투영 토큰, 참조 원본과 컬럼 이름. 명시적 컬럼 이름은 순서로 원래 슬롯과 대응한다.
- 전체 경로 노드: 범위와 출력 슬롯 또는 참조 위치로 식별하고 입력·사용처 양쪽 연결을 보존한다. 원본 관계는 객체 식별자로 구분해 같은 테이블명의 독립된 별칭을 합치지 않는다. 같은 별표 위치를 공유하는 서로 다른 컬럼 슬롯도 별개 노드다.
- 화면 상태: 요청 세대, 현재 편집기·문서, 문서 변경 시각, 목록 생성 시각, 탐색 억제 플래그. 수정·쿼리 전환·종료 시 이전 요청을 무효화한다.
- 출력 전달 범위: SELECT·FROM 아래의 쿼리 범위만 허용하고 조건·그룹·정렬 아래의 하위 쿼리는 제외한다. 조건절에서 선택한 컬럼은 표시 오프셋 없는 임시 참조로 해석하며 목록에는 SELECT 출력 단계만 남긴다.
