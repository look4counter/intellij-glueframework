# 조사 결과

- 기존 파서는 SELECT 투영 토큰의 오프셋, CTE 참조, 파생 쿼리와 바깥 범위를 보존한다. 별도 SQL 파서보다 이 구조를 재사용하는 것이 자동완성과 범위를 일치시킨다.
- 기존 이름 해석기는 출력 이름과 캐시 메타데이터를 제공한다. TRACE는 출력 슬롯의 위치를 추가로 보존해 명시 컬럼 이름 변경과 별표 전달을 연결한다.
- 우측 패널은 속성과 쿼리 목록으로 구성돼 있어 그 하단에 독립 패널을 추가할 수 있다. 요청 세대와 스냅샷으로 비동기 결과를 검증한다.
- UI 백그라운드 분석에는 플랫폼 실행기를 사용하고, 재생성된 편집기에는 설정 공급자를 통해 리스너를 다시 연결한다. 미해결 기술 질문은 없다.
