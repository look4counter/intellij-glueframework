# 설계 조사

## 직전 출처

결정: 기존 그래프의 선택 노드로 연결되는 직접 부모만 사용한다. 근거: 최상위 원본으로 바로 건너뛰지 않고 CTE·파생 출력의 전달 단계를 보존한다. 대안인 줄 번호상 이전 항목은 실제 출처와 무관하므로 제외한다. 테이블 한정자는 그래프에서 선언 노드로 선택되므로 클릭한 토큰과 선언 토큰이 다르면 선언을 먼저 이동 후보로 삼는다.

## 복수 입력과 무출처

결정: 여러 직접 부모는 선택 목록으로 표시하고 0개면 이동하지 않는다. 임의의 첫 출처 선택은 UNION·복합 표현식에서 오해를 만들므로 제외한다.

## 탐색 기록

결정: 쿼리 문서별 최대 100개 위치와 인덱스를 메모리에 저장한다. 문서 변경 시 기록을 초기화한다. 영속 저장이나 편집 후 위치 보정은 범위를 불필요하게 넓히므로 제외한다. 늦은 분석 결과와 팝업 선택에도 에디터·문서·수정 번호 유효성을 검증한다.

## 후속 결정

기본 선언 탐색 오류는 에디터 mousePressed 처리만으로 IDE 마우스 단축키 디스패처를 소유하지 못한 경로가 있으므로 전용 로컬 마우스 액션으로 처리한다. hover와 클릭은 동일한 링크 분석을 공유한다. 회색 강조는 단순 문자열 검색이 아닌 소스·컬럼 그래프 연결을 사용한다. 이름 변경 경계는 컬럼 Node의 식별자로 제한하여 테이블 그래프를 변경하지 않는다. 기존 회귀 중 이름 변경 전달 기대는 새 계약에 맞게 정정한다.

## 동명 테이블 결정

- 테이블 경로 이름은 별칭을 제거한 실제 소스 이름으로 비교한다. 별칭 e는 employee 바인딩의 사용이므로 이름 변경 경계가 아니다.
- CTE t 정의와 t 참조는 연결하되 내부 employee·다른 CTE 이름은 연결하지 않는다. 기존 코드의 전체 계보 대신 동명 구간만 표시한다.
- 회색 배경은 단순 이름 검색이 아닌 관련 노드와 소스 해석을 사용한다. 같은 이름의 다른 FROM 인스턴스·쿼리 문장·중첩 가림은 유지한다.
- 기존 SqlTraceResult.occurrences와 UI 하이라이터를 재사용하여 컬럼/테이블 강조를 전환한다.


## 2026-11-14 결정

로컬 탐색 액션과 도달할 수 없는 전용 이력을 함께 제거한다. 근거는 IDE 뒤로·앞으로를 SQL 추적에 사용하지 않는 사용자 요청이다. 대안인 대체 단축키·버튼과 IDE 전역 이력 개선은 범위를 넓히므로 제외한다. Ctrl+클릭·트리 탐색과 비동기 검증은 유지한다. 위의 이력 설계는 이전 결정이다.
