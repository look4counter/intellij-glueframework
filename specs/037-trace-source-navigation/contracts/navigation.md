# 추적 탐색 동작 계약

- SQL 편집 영역에서 Ctrl+왼쪽 클릭: 클릭 토큰의 직전 출처로 이동한다. 단일 후보는 즉시, 여러 후보는 이름·행·SQL 문맥 선택 목록을 제공한다.
- 뒤로·앞으로: SQL 추적은 IDE 단축키를 로컬 액션으로 등록하거나 처리하지 않는다. 전용 이력·대체 단축키·버튼을 제공하지 않는다. 빈 버튼 영역도 표시하지 않는다.
- 트리 클릭·Enter는 선택한 출처로 이동한다. Ctrl 없는 SQL 클릭은 기존 편집 동작을 수행한다.
- 이동은 텍스트·원본 파일·Undo를 변경하지 않는다.

## 후속 링크·강조·이름 경계 계약

- Ctrl hover: 실제 이동 후보가 있는 토큰에만 밑줄·손 커서를 표시한다. Ctrl 해제·이탈·문서 변경·해제로 제거한다.
- Ctrl+클릭: SQL 에디터의 전용 로컬 마우스 액션을 사용한다. IDE 기본 선언 이동은 중복 실행하지 않는다.
- 컬럼 이름 변경: `id AS renamed` 등에서 이름이 달라지는 간선을 연결하지 않는다. 같은 이름이라도 다른 소스는 별개다. 테이블도 아래 동명 테이블 계약에 따라 이름 변경 경계에서 멈춘다.
- 회색 배경: 연결된 컬럼의 출력·별칭·참조와 조건절 사용에 적용하며, 테이블 한정자·테이블 선언·주석·리터럴은 제외한다. 추적 트리의 조건절 표시 제외 규칙은 유지한다.

## 동명 테이블 계약

- CTE·물리 테이블·파생 테이블의 이름 경로가 같은 간선만 추적한다. 별칭은 원래 소스의 바인딩으로 해석한다.
- 테이블 선택 시 관련 정의·소스 이름·별칭 선언·한정자를 기존 회색 배경으로 표시하고 컬럼 강조를 교체한다. 컬럼 부분·주석·문자열은 제외한다.
- 다른 FROM 인스턴스·셀프 조인 바인딩·다른 문장·중첩 CTE 가림은 합치지 않는다. 같은 CTE 정의의 여러 참조는 함께 표시한다.
- Ctrl 밑줄·이동은 한정자에서 자기 선언, CTE 참조에서 같은 이름의 정의까지만 제공한다. 다른 이름의 입력 테이블로 넘어가지 않는다.
