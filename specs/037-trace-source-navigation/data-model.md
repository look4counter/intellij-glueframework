# 데이터 모델

출처 후보: 기존 SqlTraceNode를 사용하며 이름·행·SQL 문맥·오프셋을 제공한다. 선택 노드의 직접 부모를 오프셋으로 중복 제거한다.

탐색 기록: 문서 객체를 키로 수정 번호, 최대 100개 오프셋 목록, 현재 인덱스를 저장한다. 새 이동은 앞으로 부분 삭제 후 현재와 도착 위치를 추가한다. 기록 이동은 새 기록을 만들지 않는다. 수정 번호 불일치는 기록을 비우고 현재 문서 번호로 갱신한다.

클릭 요청: 에디터 객체·문서 객체·수정 번호·텍스트·클릭 오프셋·요청 순번으로 구성한다. 새 요청·문서 변경·에디터 전환·해제로 오래된 요청이 이동하지 않게 한다.

## 후속 모델

링크는 클릭 토큰의 시작·끝과 직접 출처 후보를 가진다. 컬럼 노드는 표시명과 별도로 SqlIdentifier 이름을 보관하며 이름이 같은 입력만 연결한다. 결과의 강조 범위는 동명 연결 컬럼의 실제 토큰 범위 목록이다. hover 요청은 에디터·문서·수정 번호·위치·순번을 검사하는 일시 상태다.

## 테이블 후속 모델

테이블 노드는 표시 이름 외에 SqlIdentifier 경로를 가진다. CTE 정의와 참조는 동일 CTE 이름을 사용하며 물리 테이블은 전체 스키마 경로를 사용한다. 빈 경로는 임의로 연결하지 않는다. 강조 범위는 관련 노드에 속한 정의·소스 이름·별칭·한정자 토큰이다. 기존 소스 객체 정체성과 CTE 정의 정체성을 유지한다.
