# 기능 명세: Orthogonal Wire 자석 붙이기

**작성일**: 2026-11-04
**상태**: 명세 검증 완료
**입력**: Snap 옆에 Orthogonal 버튼을 만들고 Wire 드래그가 직각 위치의 임계 범위 안에 들어가면 자석처럼 붙게 한다.

## 사용자 시나리오 및 검증

### 사용자 이야기 1: Orthogonal 토글 (우선순위: P1)

사용자는 Snap 옆의 Orthogonal 토글로 직각 붙이기를 설정한다. 독립 검증은 도구 모음 순서와 설정 공유·복원을 확인한다.

1. Snap 바로 다음에 Orthogonal 버튼이 표시되고 켜짐 상태를 확인할 수 있다.
2. Snap과 독립적으로 동작하고 열린 다른 모델 편집기 및 새 편집기에도 설정이 반영된다.
3. 초기값은 꺼짐이며 설정은 재실행 후에도 유지된다. 버튼 자체는 원문을 바꾸지 않는다.

### 사용자 이야기 2: Wire 자석 드래그 (우선순위: P1)

사용자는 Wire 꺾임점 및 선분 중앙 핸들을 움직여 인접 구간을 수평·수직으로 맞춘다. 독립 검증은 근접 이동 시 좌표와 놓은 후 원문을 확인한다.

1. 인접 꺾임점 또는 접속 노드를 기준으로 직각 위치에 가까워지면 정확한 수평·수직 좌표에 붙는다.
2. 화면상 6px 이내에서 붙고 10px를 초과하면 풀려 경계의 흔들림을 줄인다. 확대율이 달라도 화면상 감도는 같다.
3. Alt 입력 또는 토글 해제 시 자석 보정을 해제한다. 기존 Snap 설정은 유지된다.
4. 놓으면 미리보기와 같은 좌표가 저장되고 실행 취소 및 다시 실행이 가능하다. 취소 시 원래 경로를 복원한다.

### 경계 조건

- 자유 구간과 기존 Wire 접점 재연결·꺾임점 병합 동작을 보존한다.
- 원문 변경·읽기 전용·편집기 폐기 때 기존 드래그 보호를 유지한다.
- 다른 Wire 또는 다음 드래그에 이전 자석 상태가 남지 않는다.
- 기존 Wire 전체를 자동 재배치하지 않는다. 버튼은 편집 중 가까운 직각 위치에 붙이는 동작을 제어한다.

## 요구사항

- **FR-001**: Snap 바로 옆에 Orthogonal 토글을 제공한다.
- **FR-002**: 독립 설정을 기본 꺼짐으로 저장하고 편집기 사이에 공유한다.
- **FR-003**: 꺾임점 및 선분 중앙 핸들의 인접 구간을 기준으로 수평·수직 좌표에 붙인다.
- **FR-004**: 화면상 진입 6px·이탈 10px 임계 범위와 Alt 임시 해제를 적용한다.
- **FR-005**: 미리보기·확정 위치를 일치시키고 기존 실행 취소·취소·연결·병합 및 원문 보호를 유지한다.

### 주요 개체

- Orthogonal 설정: Snap과 별개인 켜짐 상태.
- 자석 드래그 상태: 현재 드래그에서 유지하는 가로·세로 기준 좌표.
- Wire 핸들: 기존 꺾임점 또는 새로운 꺾임점을 넣는 선분 중앙 위치.

## 성공 기준

- **SC-001**: 도구 모음 순서·설정 공유·직렬화 자동 검증이 통과한다.
- **SC-002**: 진입·유지·해제·Alt·확대율 및 음수 좌표 검증에서 정확한 보정 좌표를 얻는다.
- **SC-003**: 실제 Wire 드래그·저장·실행 취소·취소 및 기존 모델 편집 회귀 검증이 통과한다.

## 가정 및 명확성 검토

2026-11-04: 질문 0개. 최신 요청의 자석 동작을 기준으로 범위 밖에서는 자유롭게 이동하도록 정한다. 접점 재연결은 기존 동작을 유지한다. 전체 Wire를 자동으로 직각 라우팅하는 기능은 이번 범위에 포함하지 않는다. 기능·경계·설정·검증에 중대한 모호성 없음.
