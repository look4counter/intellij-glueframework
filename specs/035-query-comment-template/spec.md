# 기능 명세: 쿼리 머리말 주석 템플릿

**작성일**: 2026-11-08
**상태**: 명세 및 명확화 완료
**입력**: 우측 패널의 아래로 버튼 오른쪽에 최상단 주석 추가 버튼을 제공하고 GlueQueryEditor 설정의 템플릿 변수를 치환한다.

## 사용자 시나리오 및 검증

### 사용자 이야기 1: 템플릿 설정 (우선순위 P1)

사용자는 Settings > GlueQueryEditor > Tool에서 여러 줄 주석 템플릿을 편집하고 저장한다.
독립 검증: 설정 변경 감지, 초기화, 적용, 화면 재생성 및 저장 상태 복원을 확인한다.

1. 설정을 변경하면 적용 전까지 저장값은 유지되고 변경 상태가 표시된다.
2. 초기화하면 저장값으로 돌아가고 적용하면 다음 주석 삽입에 사용된다.

### 사용자 이야기 2: 주석 삽입 (우선순위 P1)

사용자는 선택한 쿼리에 주석을 한 번의 클릭으로 추가한다.
독립 검증: 주석 버튼 클릭 후 현재 쿼리의 SQL 맨 앞에 치환된 주석이 있고 기존 SQL이 유지되는지 확인한다.

1. 아래로 버튼 바로 오른쪽에 주석 추가 버튼이 있다.
2. 현재 쿼리의 최신 ID, 설명 및 현재 날짜가 치환된다.
3. 편집 중인 SQL은 보존되고 Source와 Design에 같은 결과가 표시된다.

### 경계 조건

- 선택 없음, 읽기 전용, 잘못된 XML, 중첩 태그 등 기존 SQL 편집 불가 상태에서는 삽입할 수 없다.
- 빈 템플릿은 아무것도 삽입하지 않는다. 반복 클릭은 매번 머리말을 추가한다.
- 알 수 없는 변수와 잘못된 날짜 형식은 원문을 유지한다. 치환된 값 안의 변수는 다시 치환하지 않는다.
- 줄바꿈은 편집기에 맞추고 SQL 본문 및 기존 주석은 유지한다. XML 특수문자와 CDATA 종료 문자열을 보존한다.

## 요구사항

- **FR-001**: 프로젝트별 여러 줄 주석 템플릿을 설정하고 영속 저장하며 적용·초기화·변경 감지를 지원한다.
- **FR-002**: 아래로 버튼 오른쪽에 툴팁과 접근성 이름이 있는 주석 추가 버튼을 제공한다.
- **FR-003**: `${QUERY_ID}` 및 `#{QUERY_ID}`는 현재 ID, `${QUERY_DESCRIPTION}` 및 `#{QUERY_DESCRIPTION}`는 현재 설명으로 치환한다.
- **FR-004**: `${yyyy-MM-dd}` 등 날짜·시간 형식은 사용자의 현지 시간으로 치환하며 일반 문구 및 미지원 변수는 유지한다.
- **FR-005**: 최신 편집을 반영한 SQL의 맨 앞에 주석과 줄바꿈을 삽입하며 기존 저장·동기화·실행 취소 경로를 사용한다.
- **FR-006**: 편집 불가 상태 및 지연 실행 도중 선택 변경을 방어하고 빈 템플릿은 무시한다.
- **FR-007**: 설정 화면의 주석 템플릿 아래 안내에는 달러 표기의 쿼리 ID·쿼리 설명·ResultType·현재 날짜와 시간 변수 및 각각의 의미를 표시한다. 쿼리 설명은 실제 지원하는 단수형 QUERY_DESCRIPTION으로 안내한다.
- **FR-008**: GlueQueryEditor 아래에 Tool과 Database 하위 항목을 제공한다. SQL 포매팅과 주석 템플릿은 Tool로, 데이터소스·연결 테스트·메타데이터 관리는 Database로 옮긴다. 상위 화면에는 설명과 하위 설정 링크를 표시한다.
- **FR-009**: 두 설정 화면은 독립적으로 변경 감지·적용·초기화·자원 해제를 수행하며 기존 저장값과 비밀번호 및 메타데이터 동작을 보존한다.
- **FR-010**: Settings의 GlueFramework를 선택하면 상단에 설정 범위 설명을 표시하고 직계 하위 메뉴 GlueQueryEditor·GlueModelEditor를 클릭 가능한 링크로 제공한다. IntelliJ 기본 상위 메뉴와 같은 배치·이동 방식을 사용하며 기존 하위 설정은 유지한다.
- **FR-011**: 기본 템플릿의 첫 내용 행은 `QueryId : ${QUERY_ID} / ${QUERY_DESCRIPTION}`이며 작성자·수정이력·날짜와 들여쓰기 등 나머지 예시 내용은 유지한다. 사용자 저장 템플릿은 덮어쓰지 않는다.
- **FR-012**: GlueQueryEditor를 선택하면 설정 범위 설명과 Tool·Database 링크를 IntelliJ 기본 그룹 화면으로 표시한다. 두 설정 화면의 ID와 저장값은 유지한다.
- **FR-013**: `${QUERY_RESULT_TYPE}`를 선택한 쿼리의 최신 ResultType으로 치환한다. 값이 없으면 빈 문자열로 치환하고 기존 변수와 동일하게 단일 패스로 처리한다.

### 주요 개체

- 주석 템플릿: 프로젝트별 원문 문자열. 기본값은 사용자가 제시한 예시이다.
- 치환 문맥: 선택된 쿼리 ID, 설명, 삽입 시점의 현지 날짜·시간.

## 성공 기준

- **SC-001**: 설정한 예시가 한 번의 클릭으로 정확한 ID·설명·날짜를 포함한 머리말이 된다.
- **SC-002**: 설정 적용·초기화·재생성·영속 저장 검증이 모두 통과한다.
- **SC-003**: 기존 SQL 보존, 편집 불가 상태 및 기존 편집기 회귀 검증이 통과한다.

## 가정 및 명확화 결과

- 구조·데이터·흐름·오류·제약·용어를 점검했으며 사용자에게 확인해야 할 중대한 모호성은 없다.
- 예시의 달러/샤프 표기를 모두 지원한다. 작성자는 입력한 고정 문구로 취급한다.
- 최상단은 파일 전체가 아닌 선택한 쿼리의 SQL 시작이다. 기존 주석 교체는 범위 밖이다.
- 날짜 형식은 연·월·일·시·분·초 및 구분자 조합을 지원한다. 알 수 없는 변수는 남겨 둔다.
- 새 외부 의존성이나 네트워크 연결은 필요하지 않다.
- 후속 안내 문구 변경의 명확화: 최초에는 사용자 지정 한 줄을 표시했으나 최신 요청에 따라 변수별 의미도 설명한다. 변수 치환 규칙은 변경하지 않는다.
- 설정 분리 명확화: Tool은 편집 도구 설정, Database는 데이터베이스 관련 설정이다. 기존 프로젝트별 저장 서비스는 유지하며 별도 데이터 이전은 필요 없다. 추가 확인이 필요한 모호성은 없다.
- 상위 화면 명확화: 링크는 직계 하위 항목 두 개로 제공한다. Tool·Database는 GlueQueryEditor 아래의 기존 계층을 유지한다. 사용자 요청의 기본 메뉴와 같은 화면은 플랫폼 기본 그룹 화면 사용으로 충족하며 추가 질문은 없다.
- 기본 문구 및 변수 설명 변경은 기존 저장값을 보존하는 기본값·안내 변경이다. 추가 확인이 필요한 모호성은 없다.
- 최신 요청의 명확화: GlueQueryEditor도 기본 그룹으로 바꾸고 기본 예시·안내는 달러 표기로 통일한다. 기존 샤프 표기 치환 호환성은 유지한다. QUERY_RESULT_TYPE은 사용할 수 있는 변수와 안내에 추가하며 기본 예시에 새 행을 넣지는 않는다.
