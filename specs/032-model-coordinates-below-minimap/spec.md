# 기능 명세: 미니맵 아래 좌표 표시

작성일: 2026-11-08
상태: 명확화 완료
입력: ModelEditor 좌측 상단의 x·y 좌표를 제거하고 미니맵 아래에 표시한다.

## 사용자 시나리오와 검증

### 사용자 이야기 1: 위치 정보 모으기 (P1)

사용자는 화면 좌측 상단 대신 미니맵 아래에서 현재 x·y 좌표를 확인한다. 화면을 이동하거나 미니맵으로 탐색할 때 기존과 같은 값이 갱신된다. 기존 다이어그램 속성 표시는 좌측 상단에 남는다.

## 요구사항

- FR-001: x·y 좌표를 좌측 상단에서 그리지 않고 미니맵 프레임 아래에 표시한다.
- FR-002: 기존 pan 좌표의 값·반올림·문구 형식을 유지한다. 이동 중 캐시를 사용해도 현재 값을 표시하고 줌에 의해 글자가 확대되지 않는다.
- FR-003: 미니맵 표시 위치에 따라 좌표 표시도 배치한다. 미니맵이 없는 경우 좌표는 숨긴다. 기존 좌측 속성·미니맵 클릭/드래그·이동·줌·모델 데이터를 유지한다.
- FR-004: 위치·이동 중 갱신과 관련 미니맵·탐색·속성 회귀를 확인하고 결과를 기록한다.

## 주요 개체

- 좌표 문구: 현재 pan.x·pan.y의 반올림 값.
- 위치 기준: 화면 좌표계의 미니맵 프레임과 글꼴 메트릭.

## 성공 기준

- SC-001: 좌측 상단에 좌표가 없고 미니맵 아래에서 좌표가 보이며 화면 이동 시 갱신된다.
- SC-002: 관련 미니맵 탐색·줌·속성·캐시 회귀와 ZIP·구조 검사가 통과한다.

## 가정과 명확화

질문 0개. 마우스 위치 등 새로운 좌표값을 도입하지 않고 기존 화면 이동 좌표를 옮긴다. 미니맵이 없는 빈 모델·작은 화면에서는 좌표도 표시하지 않는다. 좌측 속성은 좌표가 차지하던 빈 줄 없이 표시한다.
