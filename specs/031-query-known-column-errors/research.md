# 조사 결과

- 기존 SqlQueryScope는 이름 목록만 반환해 불명 별표와 빈 출력 집합을 구분할 수 없다. 검증기는 이름·위치와 출력 개수의 불확정 여부를 별도로 유지해야 오탐을 막을 수 있다.
- 기존 파서는 SELECT·CTE·파생 범위를 보존한다. DML 확장은 검증 전용 모드로 제한해 기존 자동완성·TRACE 동작을 바꾸지 않는다.
- QuerySqlEditor는 일반 텍스트 PSI 문서와 자체 렉서를 사용한다. 편집기 markupModel에 IDE ERROR 속성의 범위 표시를 설치하면 문서 변경이나 새 SQL 언어 플러그인 없이 의미 오류를 보여줄 수 있다.
- 기존 색상 키가 밝은/어두운 JBColor를 사용하므로 주석도 같은 방식으로 별도 키를 제공한다. 미해결 기술 질문은 없다.
