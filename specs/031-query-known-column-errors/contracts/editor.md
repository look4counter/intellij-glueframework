# 편집기 계약

- 확정 CTE·파생 관계의 없는 컬럼은 식별자 부분에 빨간 오류 물결선과 설명을 제공한다.
- 대상은 전체 지원 구역이다. 불명 물리 테이블·별표 등에는 부재 오류를 만들지 않는다.
- 수정·쿼리 전환 시 표시를 갱신하며 읽기만 하고 Source·Undo를 변경하지 않는다.
- 한 줄·블록 주석은 밝은 테마에서 진한 녹색, 어두운 테마에서 밝은 녹색을 사용한다.

## NULL 리터럴 보호

SELECT NULL 및 NULL AS 별칭을 포함한 비인용 단독 NULL은 컬럼 부재 오류로 표시하지 않는다. 같은 문장의 실제 누락 컬럼, t.NULL 및 인용된 "NULL" 식별자는 기존 확정 컬럼 검증을 유지한다. SQL·Source·Undo는 검사 때문에 변경하지 않는다.
