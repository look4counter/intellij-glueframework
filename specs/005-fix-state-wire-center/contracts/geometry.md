# 경로·크기 조절 계약

상태 끝점은 중심 방향의 원 외곽이다.
Snap은 양쪽 Activity의 유효 후보 중 가장 가까운 것을 선택한다.
Resize 시 내부 꺾임점의 절대 좌표는 유지하고 양 끝 접점은 Activity 경계 규칙을 따른다.
미리보기와 XML 저장에 동일한 보정 함수를 사용하며 저장 시 weight와 추가 속성을 보존한다.

Snap은 Wire와 Child 정렬의 공통 토글이다. 꺼짐에서는 보조선과 좌표 흡착을 적용하지 않는다. 최소 너비는 항상 유지한다.


Snap 상태는 애플리케이션 전역의 마지막 값이며 열린 편집기 전체와 새 편집기가 공유한다. 설정 복원 시에도 열린 화면을 갱신한다.
