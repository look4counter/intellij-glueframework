# 조사 결과

- 결정: Resize된 끝 노드의 중심 차이를 해당 꺾임점 벡터에서 뺀다.
- 근거: 실제 꺾임점은 두 중심에 상대 벡터를 더한 위치들의 비율 보간이다. 중심과 벡터를 반대 방향으로 보정하면 보간 전후 위치가 같다.
- 대안: 표시 시에만 보정하면 저장 후 재열기에 문제가 되므로 미리보기와 XML 쓰기가 공유하는 relocateNodes에 적용한다.
- 저장: 기존 bendpoint 태그에 두 차원 속성만 쓰므로 weight와 사용자 속성을 보존한다.
- Magnetic: 사용자의 명시 지시에 따라 최근접 후보 선택을 복원한다.
- 미해결 기술 질문은 없다.

## Snap 조사

Wire와 Child 정렬이 별도 조건으로 동작하고 있어 공통 토글을 Child 계산 진입점에 적용한다.
기본값은 기존 Wire 토글의 꺼짐이다. 최소 너비는 정렬과 무관한 필수 제약이다.


## 전역 상태 조사

기존 Snap은 각 Canvas의 메모리 값이라 편집기를 새로 만들면 꺼진다.
기존 ModelEditorSettings는 프로젝트 범위이므로 전역 토글은 별도 애플리케이션 서비스로 둔다.
애플리케이션 메시지 버스와 편집기 Disposable 연결을 사용하여 프로젝트 경계와 편집기 수명을 일치시킨다.
추가 외부 의존성이나 미해결 기술 질문은 없다.
