# 기능 명세: SQL 포매팅 정렬 옵션

작성일: 2026-11-07
상태: 명확화 완료
입력: Settings > GlueFramework > GlueQueryEditor에 WHERE 등호와 SELECT AS의 열 정렬 체크박스를 추가한다.

## 사용자 시나리오와 검증

### 사용자 이야기 1: 스타일 저장 (P1)

사용자는 WHERE 등호 정렬과 SELECT AS 정렬을 개별로 선택한다. 기본값은 둘 다 해제다. Apply/OK로 저장하며 Reset/Cancel은 미적용 변경을 버린다. 프로젝트를 다시 열어도 저장값을 유지한다.

### 사용자 이야기 2: 설정에 따른 포매팅 (P1)

WHERE AB = AB와 AND HELO = HI에서 옵션을 켜면 AB 뒤에 공백을 추가해 두 등호가 가장 오른쪽 등호 열에 맞춰진다. SELECT의 각 출력 별칭 AS도 같은 방식으로 가장 오른쪽 AS 열에 맞춘다. 각 옵션을 껐을 때는 기존 포매팅을 따른다.

### 경계 조건

CTE·서브쿼리·UNION·다른 SQL 문장은 각각 독립적으로 정렬한다. 주석·문자열·파라미터 내용은 보존한다. 비교 연산자 >=·<=·!=·<>를 단독 등호로 취급하지 않고 CAST의 AS와 테이블 별칭 AS는 SELECT 출력 별칭과 섞지 않는다. CASE·서브쿼리를 포함해도 기존 들여쓰기와 재포매팅의 동일성을 유지한다.

## 요구사항

- FR-001: GlueQueryEditor 설정에 `WHERE절 등호에 맞춰 정렬`, `SELECT절 AS에 맞춰 정렬` 두 체크박스를 제공한다. 둘 다 기본 해제이며 독립적이다.
- FR-002: 프로젝트 설정으로 저장하고 Apply·변경 감지·Reset·취소·화면 재생성·이전 설정의 기본값 복원을 지원한다. 기존 DataSource 설정을 훼손하지 않는다.
- FR-003: WHERE 정렬 옵션을 켜면 같은 WHERE의 각 조건 줄에 있는 첫 단독 등호를 가장 오른쪽 등호 열에 맞추도록 앞에 공백을 추가한다. 다른 연산자는 대상으로 삼지 않는다.
- FR-004: SELECT 정렬 옵션을 켜면 같은 SELECT의 출력 별칭 AS를 가장 오른쪽 AS 열에 맞추도록 앞에 공백을 추가한다. CAST·CTE 선언·FROM의 AS는 대상으로 삼지 않는다.
- FR-005: 각 쿼리 블록·절·문장은 독립적으로 정렬하며 문자열·주석·파라미터와 기존 구문 들여쓰기를 보존한다. 반복 실행 결과는 동일하다.
- FR-006: Query Design의 전체·선택 영역 포매팅 모두 현재 저장 설정을 적용하고 Source 동기화·Undo/Redo·선택 밖 보존을 유지한다. 설정을 저장하는 것만으로 SQL을 자동 수정하지 않는다.
- FR-007: 설정 수명·직렬화·검증 실패와 포매터 경계·실제 편집기 적용을 자동 검증하고 사용법을 기록한다.
- FR-008: SQL 포매팅 스타일 영역은 사각 테두리로 감싸지 않고 IntelliJ 기본 설정 화면의 제목·가로 구분선·들여쓴 체크박스 배치를 사용한다. 테마·배율과 기존 옵션의 저장·복원 동작은 유지한다.

## 주요 개체

- 포매팅 설정: WHERE 등호 정렬 여부, SELECT AS 정렬 여부.
- 정렬 그룹: 같은 구역의 대상 토큰과 기준 열. 다른 쿼리 블록의 기준은 공유하지 않는다.

## 성공 기준

- SC-001: 체크 해제·개별 선택·동시 선택의 기대 결과와 저장·복원 검증이 통과한다.
- SC-002: 중첩·주석·문자열·비교 연산자·CAST·CASE·선택 영역·반복 실행 회귀 검증이 통과한다.
- SC-003: 전체 테스트·설치 ZIP 생성·플러그인 구조 검사가 통과한다.

## 가정과 명확화

질문 0개. 기존 프로젝트별 GlueQueryEditor 설정 범위에 맞춘다. 단독 등호와 명시적 출력 별칭 AS 앞의 공백만 늘리며 컬럼 이름이나 식을 수정하지 않는다. 옵션은 사용자가 포매팅을 실행할 때 적용된다. ON·HAVING·UPDATE SET의 등호 정렬은 이번 WHERE 옵션에 포함하지 않는다.

설정 화면 보완의 명확화 질문 0개. 사각 TitledBorder를 제거하고 IntelliJ의 기본 제목 구분선 컴포넌트를 사용한다. 체크박스 두 개의 문구·기본값·설정 범위는 유지한다.
