# 설정·포매팅 계약

- 위치: Settings > GlueFramework > GlueQueryEditor의 SQL 포매팅 스타일 영역.
- 이름: WHERE절 등호에 맞춰 정렬, SELECT절 AS에 맞춰 정렬.
- 외형: IntelliJ 제목 구분선 아래에 들여쓴 체크박스를 배치하며 영역 전체를 사각 테두리로 감싸지 않는다.
- 두 옵션은 독립적이며 기본 해제다. Apply/OK는 프로젝트에 저장하고 Reset/취소는 미적용 초안을 버린다.
- 적용은 사용자가 SQL 포매팅을 실행할 때 일어난다. 선택 영역이 있으면 선택 밖 텍스트는 그대로 유지한다.
- 비교 대상은 같은 절의 단독 등호 또는 SELECT 출력 별칭 AS다. 가장 오른쪽 대상의 열에 맞춰 공백을 추가한다.
