# 데이터 모델

- Design 선택: 공유 Document의 스마트 query 포인터. 삭제되어 무효화되거나 목록에 없으면 첫 query를 사용한다.
- Source 위치: 공유 Document의 정수 오프셋. Source 비활성화 때 기록하고 Design 활성화 때 소비한다.
- 활성화 세대: 편집기별 증가 값. 이전 세대의 지연 실행과 폐기 후 실행을 무시한다.

원문 문서와 실행 취소 이력의 형식은 바뀌지 않는다. Source 위치는 query 범위 시작을 포함하고 끝은 제외한다. 중첩 태그와 CDATA도 바깥 query 범위로 판단한다.
