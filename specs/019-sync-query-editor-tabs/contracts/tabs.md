# 탭 전환 계약

- Design → Source: 최신 선택 query 시작으로 이동하고 화면에 표시한다. 대응 query가 없으면 첫 query 시작으로 이동한다.
- Source → Design: 커서가 포함된 query를 선택하고 목록에 표시한다. 대응 query가 없으면 첫 query를 선택한다.
- query가 없거나 원문이 잘못되면 예외를 내지 않고 기존 오류·빈 상태를 유지한다.
- 탭 전환은 원문을 저장하지 않으며 탐색만으로 문서를 수정하지 않는다. Design의 대기 중 수정은 기존 적용 경로로 먼저 반영한다.
- 폐기되거나 더 최신 활성화가 있으면 이전 예약 작업은 무시한다.
보완: 양방향 SQL 글자 위치를 보존한다. Design → Source는 최신 본문의 같은 글자로 이동하며 본문이 없으면 query 시작을 사용한다. Source의 속성·태그는 Design의 쿼리별 마지막 위치 또는 SQL 처음으로 대체한다. 문서 갱신과 반복 전환으로 커서가 끝으로 이동하지 않아야 한다.
