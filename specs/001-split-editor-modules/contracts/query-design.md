# 쿼리 Design 계약

## 입력과 레이아웃

queryeditor/sample-query.glue_sql을 기준으로 queryMap 루트와 같은 네임스페이스의 직접 query 자식을 읽는다. 오른쪽 순서는 queryMap desc 입력 → id·desc·resultType·isNamed 입력 → query.id 목록이다. isNamed는 체크박스이며 나머지는 문자열 입력이다. 왼쪽은 다중 행 SQL 편집기다.

오른쪽 선호 너비는 320픽셀, 최소 너비는 220픽셀이다. 구분선으로 크기를 조절한다. 첫 query를 기본 선택하고 id 변경 후에도 같은 태그의 선택을 유지한다.

## 수정

속성 또는 SQL 변경은 같은 파일의 XML 문서에 반영한다. 선택을 바꾸기 전에 이전 query의 대기 변경을 처리한다. SQL 표시에서 CDATA 마커를 제거하고 entity를 디코딩하며 저장할 때 XML을 깨뜨리지 않도록 CDATA로 처리한다. 다른 query, 네임스페이스와 주석은 보존한다. 루트 desc는 최상단 입력으로 별도 수정한다.

잘못된 XML과 queryMap이 아닌 문서는 입력을 비활성화하고 Source에서 수정하도록 안내한다. 읽기 전용 파일은 입력을 제한한다. query 본문에 하위 요소나 주석이 있으면 SQL 본문만 쓰기 제한한다. 없는 id는 안내 문자열로 표시하고 중복 id는 별도 행을 유지한다.

## 범위

SQL 오류 진단·실행, query 추가/삭제, modeleditor Design 기능은 추가하지 않는다. SQL 토큰 색상과 키워드 자동완성은 제공한다. Source XML 편집과 기존 단일 플러그인 배포는 유지한다.

queryMap desc는 빈 목록에서도 편집 가능하며 누락 시 빈 값이다. Source 동기화·실행 취소·다시 실행·저장과 쓰기 제한을 적용한다. isNamed는 resultType과 같은 행 오른쪽이다. 하단 개수는 표시하지 않고 필요한 안내만 표시한다.

## 라벨과 클래스 완성

화면 라벨은 Id, Desc, ResultType, IsNamed이고 XML 키는 id, desc, resultType, isNamed다. ResultType은 Java 참조 한 줄 입력으로 프로젝트와 의존 라이브러리의 클래스 후보를 제공한다. 후보 선택은 전체 클래스명을 저장한다. 수동 완성은 Ctrl+Space이며 자동 팝업은 IDE 설정을 따른다. 직접 입력·비우기를 허용한다. Java 플러그인이 필요하고 인덱싱 중에는 IDE 기본 제한을 따른다. 기존 동기화·실행 취소·다시 실행·저장·쓰기 제한을 유지한다.

## 파일 형식 아이콘

.glue_sql은 하늘색 원과 흰색 Q를 사용한다. 대응 모델 파일 .glue_uml_ad는 연주황 원과 흰색 M을 사용한다. IDE의 파일 형식 아이콘으로 제공하며 기존 확장자와 XML 연결을 유지한다.

## 최종 속성 표시와 스타일

기존 라벨 계약을 갱신하여 ID, Description, ResultType으로 표시한다. ResultType 오른쪽 체크박스는 화면 텍스트 없이 제공하고 접근성 이름·툴팁은 isNamed다. ResultType은 ID 문자열 입력과 같은 스타일을 사용하면서 Java 클래스 후보 완성과 전체 이름 저장을 유지한다. XML 속성명은 기존 그대로다.

## ResultType 실제 표시 기준

입력 안의 텍스트는 세로 중앙, 좌우 기본 여백은 각각 6픽셀이다. 일반 테두리는 1픽셀이고 포커스 시 테마 포커스 색의 2픽셀 테두리로 바뀐다. IDE 배율을 적용하며 포커스 전후 내용 위치는 유지한다. 클래스 완성 및 기존 편집 동작은 동일하다.

최종 ResultType 치수는 기존 높이보다 2픽셀 작고, 테두리 안쪽의 좌우 패딩은 각각 1픽셀이며 위치는 오른쪽으로 2픽셀 이동한다. 배율을 적용하고 기존 너비·중앙 정렬·테두리·자동완성을 유지한다.

## 열기 및 저장 시 SQL 본문 정리 계약

.glue_sql을 열거나 실제 저장하기 직전에 queryMap과 같은 네임스페이스의 직접 query 자식 중 순수 텍스트 본문을 정리한다. Source·Design 모두에 적용하며 앞뒤 공백·탭·줄바꿈만 제거한다. CDATA 바깥 본문 들여쓰기와 안쪽 여백도 포함하고 내부 줄바꿈·들여쓰기는 보존한다. 변경이 필요한 본문은 기존 Design 편집과 같은 안전한 CDATA 표현으로 저장한다. 파일 열기에서는 안전한 UI 실행으로 예약하여 문서에만 반영하고 자동 저장하지 않는다. 실행 전에 파일이 닫히거나 프로젝트가 폐기되면 정리를 건너뛴다.

중복 id의 각 쿼리는 독립적으로 처리하고 속성·네임스페이스·본문 바깥 문서는 보존한다. CDATA 종료 문자열은 여러 CDATA 구간으로 분할하여 값과 XML 유효성을 유지한다. 공백만 있는 SQL은 빈 CDATA가 된다. 중첩 요소나 XML 주석이 섞인 본문·잘못된 XML·읽기 전용 문서·다른 파일 형식은 정리하지 않는다. 반복 저장으로 추가 변경을 만들지 않으며 실행 취소와 Design 동기화를 지원한다.

## SQL 구문 색상과 키워드 완성 계약

Design SQL 입력은 DBeaver 공통 예약어·확장·실행·DDL 키워드 목록 367개를 공유하여 강조와 완성을 제공한다. 키워드는 대소문자 무시로 주황색, 정수·소수·지수·16진 숫자는 파란색, 작은따옴표·큰따옴표 토큰은 녹색이다. 식별자 일부나 이름 있는 매개변수는 키워드로 분리하지 않는다. 반복 따옴표·역슬래시 이스케이프·미완성 따옴표와 줄·중첩 블록 주석을 처리한다. 주석 내부 토큰은 따로 강조하지 않는다.

키워드 접두어 완성은 Ctrl+Space 및 IDE 자동 팝업을 사용한다. 문자열·주석·숫자·읽기 전용 입력에서 후보를 제시하지 않으며 일반 문서 단어가 SQL 키워드 후보와 섞이지 않는다. 후보 선택은 현재 SQL 버퍼에 삽입되어 선택한 query XML에만 반영된다. 쿼리 전환·실행 취소·Source 동기화·열기 및 저장 정리 후에도 강조와 완성을 유지한다. Source의 XML 언어와 ResultType의 Java 클래스 완성은 변경하지 않는다.

밝은 테마 기본 색상은 주황 #C46600·파랑 #175BC1·녹색 #26823B이고 어두운 테마는 주황 #FFA657·파랑 #6CA8F5·녹색 #78C78B이다. SQL 구문 오류 진단·실행 및 DB 스키마 기반 완성은 제공하지 않는다.
## 파라미터 표시와 DataSource 설정 계약

`:name` 전체는 cyan이며 문자열·주석·`::type`·`:=`는 파라미터에서 제외한다. 파라미터 내부 키워드 완성은 제공하지 않는다. 쿼리 목록 셀 좌우에 배율 적용 8픽셀을 추가하고 줄 번호 오른쪽에 최소 8픽셀을 확보한다.

Settings > GlueFramework > GlueQueryEditor는 프로젝트별 DataSource 목록을 관리한다. 이름과 유효한 `jdbc:` URL을 요구하며 대소문자를 무시한 중복 이름은 거부한다. 드라이버 클래스·사용자명·비밀번호는 선택 항목이다. Apply 이전의 입력·삭제는 초안이며 Reset/Cancel로 폐기한다. 비밀번호는 공백 입력 시 유지하고 명시적 삭제 또는 항목 삭제 시 제거한다. 보안 저장소 작업 실패 시 메타데이터를 적용하지 않고 재시도를 허용한다. 실제 연결과 실행은 이 계약에 포함하지 않는다.

## 선택 DB 메타데이터 계약

줄 번호 예약은 이제 18픽셀이다. Settings의 목록은 고정 너비이며 DB 종류·복수 JAR 지정·자동 다운로드를 제공한다. 에디터 상단에서 프로젝트 DataSource를 선택한 뒤 새로고침하면 접근 가능한 테이블과 각 컬럼 이름을 읽는다. 성공 캐시의 Distinct 이름은 키워드와 함께 완성 후보가 된다. 접두어 검색은 대소문자를 무시하며 원본 이름의 정확한 일치로 중복을 제거한다. DB를 고르지 않으면 키워드만 제공한다.

기존 문자열·주석·파라미터·숫자·읽기 전용 완성 제외 규칙을 유지한다. 새로고침 실패 시 안전한 오류와 기존 성공 캐시를 유지하며 설정 변경·삭제는 캐시를 비운다. 다운로드는 버튼을 누를 때만 실행되고 실패하면 기존 JAR 초안을 보존한다. Impala는 직접 HTTPS JAR/ZIP 배포 주소를 입력해야 한다. 메타데이터 조회 외의 SQL 실행은 지원하지 않는다.
