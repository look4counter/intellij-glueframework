# 기능 명세: 대규모 모델 화면 최적화

**작성일**: 2026-10-27
**상태**: 명확화 완료
**입력**: 미니맵 캐시, 화면에 보이는 요소 그리기, 드래그 시 변경된 요소 갱신 순서로 최적화한다.

## 사용자 시나리오와 검증

### 사용자 이야기 1 — 미니맵을 유지하며 부드럽게 탐색 (우선순위: P1)

사용자는 요소가 많은 모델에서 마우스를 이동하거나 화면을 다시 그릴 때 전체 미니맵을 반복 계산하는 지연을 줄인다.

**독립 검증**: 큰 모델을 반복 표시하고 미니맵 조회·그리기의 작업량과 결과를 비교한다.

1. 모델과 화면 상태가 같으면 미니맵 표시를 재사용한다.
2. 팬·줌·스크롤·크기 변경 후 미니맵 표시와 클릭·드래그 탐색 위치가 정확하다.
3. 모델·설정 색상·폰트·테마·변경 강조가 바뀌면 최신 모습을 표시한다.

### 사용자 이야기 2 — 보이는 영역을 빠르게 그리기 (우선순위: P2)

사용자는 화면 밖에 많은 요소가 있어도 현재 보이는 도형과 선을 정상적으로 확인한다.

**독립 검증**: 작은 화면에 큰 모델을 표시하고 그리기 작업량과 화면 픽셀을 비교한다.

1. 화면 밖의 요소는 본 화면에서 그리지 않되 미니맵에는 유지한다.
2. 끝점이 화면 밖에 있어도 화면을 가로지르는 Wire와 화면 안으로 들어오는 라벨·화살표는 표시한다.
3. 선택 핸들·주 선택 순서·생성 미리보기·정렬 안내선·삭제 강조와 부분 다시 그리기를 보존한다.

### 사용자 이야기 3 — 드래그 시 필요한 부분만 갱신 (우선순위: P3)

사용자는 Child 이동·크기 조절과 Wire 편집에서 변경에 영향을 받지 않는 요소의 계산을 반복하지 않는다.

**독립 검증**: 연결된 Wire와 무관한 Wire가 섞인 큰 모델에서 연속 드래그를 수행한다.

1. 이동·크기 조절된 Child와 연결된 Wire만 위치·경로를 갱신한다.
2. Wire 끝점·꺾임점 편집 시 해당 Wire만 경로를 갱신한다.
3. 연속 이동은 누른 시점의 원본을 기준으로 계산하고, 취소하면 원본으로 복원한다.
4. 드래그 임계치·스냅·다중 선택·연결 보존·실행 취소·재실행·저장을 유지한다.

### 경계 조건

빈 모델, 잘못된 연결, 음수 좌표, 긴 라벨, 양끝이 화면 밖인 선, 확대·축소, 화면 크기 및 테마 변경을 다룬다. 캐시는 각 에디터가 소유하고 모델 전환 및 에디터 제거 시 오래된 객체를 무제한 보관하지 않는다.

## 요구사항

- **FR-001**: 동일 상태의 미니맵 계산과 배경 그리기를 재사용해야 한다.
- **FR-002**: 모델·스타일·화면 변화를 반영하고 기존 미니맵 탐색을 유지해야 한다.
- **FR-003**: 본 화면은 표시 영역에 영향을 주는 요소만 그리며 Wire·라벨·화살표·선택 표시가 잘리지 않아야 한다.
- **FR-004**: 드래그에서는 변경된 Child와 연결된 Wire 또는 직접 편집한 Wire만 기하 정보를 다시 계산해야 한다.
- **FR-005**: 기존 편집·정렬·스냅·생성·강조·실행 취소·저장을 보존해야 한다.
- **FR-006**: 동일한 큰 모델로 수정 전후 반복 조회·화면 그리기·드래그 비용과 작업량을 비교하고 결과를 기록해야 한다.
- **FR-007**: 저성능 그래픽 환경의 화면 갱신 부담을 줄이도록 Child 이동·크기 조절과 Wire 편집에서 변경 전후 도형·선·라벨·핸들 및 미니맵 영역을 갱신한다. 안내선 표시·제거 등 안전한 부분 갱신이 어려운 경우 전체 갱신을 허용한다. 팬·영역 선택은 기존 전체 갱신을 유지한다.

### 주요 개체

화면에 표시하는 모델, 현재 화면 영역과 배율, 미니맵 표시, 노드와 연결된 Wire, 색상과 변경 강조를 다룬다. 모델 파일이나 저장 형식은 변경하지 않는다.

## 성공 기준

- **SC-001**: 동일 상태에서 미니맵을 100회 조회하고 반복 그려도 전체 모델의 미니맵 재계산·재그리기는 최초 1회 이내다.
- **SC-002**: 화면에 일부만 보이는 2,000개 Child 모델의 캐시 준비 후 본 화면 그리기 대상은 전체 Child의 10% 이하다.
- **SC-003**: Child 하나와 Wire 하나를 편집할 때 무관한 Wire의 경로 및 객체를 재생성하지 않는다.
- **SC-004**: 기존 기능 및 화면 경계·캐시 무효화·취소 회귀가 모두 통과하고, 동일 환경에서 수정 전후 측정 결과를 보고한다. 시간 측정은 절대 시간 제한으로 테스트를 불안정하게 만들지 않는다.
- **SC-005**: 안내선 없는 작은 요소의 연속 드래그는 전체 화면보다 작은 영역을 갱신하며, 부분 갱신을 누적한 화면은 전체 갱신 결과와 픽셀 단위로 일치한다. 지원 확대율 50%·100%·150%, 연결 Wire, 끝점·꺾임점 편집을 자동 검증한다.

## 가정 및 명확화

사용자가 승인한 세 단계 순서를 따른다. 미니맵의 기능이나 표시 내용을 줄이지 않는다. 성능 측정용 합성 모델과 자동 회귀를 추가한다. 실제 사용자 모델은 제공되지 않았으므로 합성 모델 측정과 실제 체감 속도를 구분한다. 범위·상태·호환성·검증 기준·경계 조건을 검토했으며 추가 질문이 필요한 모호함은 없다.

### 2026-11-06 명확화

사용자의 저성능 GPU 환경 드래그 지연 제보에 따라 기존 최적화의 화면 갱신 범위를 보완한다. 그래픽 품질과 입력 좌표·스냅·확정·취소 계약은 유지한다. 실제 GPU와 모델 정보가 없어 체감 개선율을 보장하지 않고 갱신 면적과 회귀로 검증한다. 범위·자료·상호작용·품질·외부 의존성·경계 조건을 검토했으며 추가 필수 질문은 없다.
