# 데이터 모델

- 모델 세대: 외부 모델 교체 또는 부분 기하 변경 시 증가한다.
- Wire 렌더링 정보: 현재 Wire 참조, 끝점 미리보기 값, 경로 점, 라벨 경계와 경로 경계를 가진다. 현재 모델 범위만 보관한다.
- 범위 인덱스: 노드 및 Wire 위치별 사각형과 각 축 좌표의 개수를 가진다. 부분 변경 시 이전 범위를 제거하고 새 범위를 추가한다.
- 미니맵 투영: 모델 세대·폰트·화면 영역·팬·원점·줌으로 유효성을 판단한다.
- 미니맵 이미지: 투영의 배율·상대 오프셋·프레임 크기·장치 배율·스타일을 키로 한다. 부분 변경 영역은 이전·현재 경계의 합집합이다. 현재 뷰포트는 이미지에 굽지 않는다.
- 드래그 인덱스: 눌렀을 때의 모델을 기준으로 선택 노드의 목록 위치와 연결 Wire의 목록 위치를 보관한다. 제스처 종료·취소·모델 교체 시 해제한다.

모델의 저장 형식과 영속 설정에는 변경이 없다.
# 2026-11-06 갱신 영역

부분 변경 집합은 기존 노드 위치와 Wire 위치 집합을 사용한다. 갱신 영역은 이전·이후 요소 경계와 미니맵 프레임을 합친 화면 사각형이다. 영속 데이터와 저장 형식은 변경하지 않는다.
