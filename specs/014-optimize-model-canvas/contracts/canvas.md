# 화면 및 편집 계약

기존 좌표·배율·히트 테스트·도형과 Wire 순서·주 선택 레이어를 유지한다. 미니맵에는 전체 모델을 표시하며 클릭·드래그에 사용하는 좌표 투영은 표시된 이미지와 일치한다. 본 화면은 현재 클립에 영향을 주는 도형·선·라벨·화살표·강조·핸들을 유지한다. 팬·스크롤·줌과 부분 다시 그리기에서 잔상이 없어야 한다.

Child 이동과 크기 조절은 원본에서 현재 포인터까지의 전체 변화를 계산한다. 끝점과 꺾임점 편집은 기존 연결·스냅·보간 계약을 따른다. 취소·읽기 전용 전환·외부 문서 변경 시 기존 복원 및 오래된 편집 방지를 유지한다. 설정·테마·폰트·변경 강조가 바뀌면 다음 표시에서 반영한다.
