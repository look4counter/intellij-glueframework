# 설계 조사

- 결정: Wire 선택을 놓음에서 확정하고 기존 클릭 경로와 선택 함수를 공유한다.
- 근거: 이동을 동반한 누름·놓음은 Swing의 클릭 이벤트를 보장하지 않는다. 현재는 이동 중 미리보기만 갱신한다.
- 중복 방지: 기존 suppressEditClick을 놓음 처리 전에 설정하고 다음 누름에서 초기화한다. 콜백 중 모델이 교체돼도 클릭을 재처리하지 않는다.
- 수명: 누름 상태는 모드 전환과 clearGesture에서 해제한다. 무효 놓음도 후속 클릭은 제외한다.
- 대안: 이동 거리 제한은 기존 문제를 남긴다. 시간·위치 기반 중복 방지는 연속 입력을 잘못 차단할 수 있어 사용하지 않는다.
