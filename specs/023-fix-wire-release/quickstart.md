# 검증 절차

Wire 모드에서 시작 요소와 끝 요소를 각각 누른 채 움직여 놓는다. 클릭 이벤트가 없어도 미리보기와 연결 요청이 발생해야 한다. 후속 클릭을 보내도 요청은 하나이며 다음 시작점이 생기지 않아야 한다.

일반 클릭, 미니맵·외부·빈 공간·같은 요소, 취소·모드 전환·모델 교체, 읽기 전용·오류 모델과 확대 상태를 검증한다. 기존 스냅·미니맵·패닝·확대 검증도 실행한다.

기존 .gradle-validation/panning-compile.args에 새 테스트와 ModelEditorFeaturesTest를 추가한 별도 인자 파일로 직접 Kotlin 컴파일 후 JUnitCore로 실행한다. Gradle 빌드는 이전 검증에서 IntelliJ 배포 ZIP 의존성이 오프라인 저장소에 없어 실패했다. 플러그인 ZIP 재생성 여부는 결과에 별도 기록한다.

## 검증 결과

2026-11-06: 모델 편집기 소스와 관련 테스트 직접 컴파일에 성공했다. 새 Wire 입력 테스트 7개와 기존 기능·서비스·클립보드·성능·미니맵·확대·배치 테스트를 합친 93개가 모두 통과했다. 클릭 없는 입력, 후속 클릭 중복 방지, 콜백 중 모델 갱신, 무효 위치, 취소·모드 전환·모델 교체, 권한·오류 모델, 우클릭과 확대 좌표를 확인했다.

컴파일·실행 인자는 .gradle-validation/wire-release-compile.args와 wire-release-test.args이며 결과 로그는 같은 디렉터리의 wire-release-compile.log와 wire-release-test.log이다. 기존 IntelliJ 배포 ZIP 의존성 누락으로 플러그인 ZIP은 재생성하지 못했다.
수렴 점검: 요구사항 4개, 성공 기준 3개와 사용자 이야기·경계 조건, 공통 선택·누름 수명·후속 클릭 제외 설계를 대조했다. 누락·부분 구현·충돌·미요청 변경은 없으며 추가 작업은 없다. 헌장은 미작성 템플릿으로 규범 검사를 생략했다.
