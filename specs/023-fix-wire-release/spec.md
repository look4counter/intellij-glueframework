# 기능 명세: 이동하며 클릭한 Wire 추가 입력 보완

작성일: 2026-11-06. 상태: 명세 검증 완료.
입력: Wire 추가 중 마우스를 움직이며 클릭하면 동작하지 않는 문제를 보완한다.

## 사용자 시나리오 및 검증

### 사용자 이야기 1: 놓은 위치에서 연결점 선택 (우선순위 P1)

사용자는 Wire 추가 모드에서 시작 요소와 끝 요소를 각각 선택한다. 버튼을 누른 채 움직여도 놓은 위치를 기준으로 선택한다.

1. 시작 요소에서 누른 뒤 이동해 놓으면 클릭 이벤트 없이 시작점이 선택된다.
2. 끝 요소에서 누른 뒤 이동해 놓으면 연결을 한 번 확정한다.
3. 일반 클릭과 이동을 동반한 클릭을 섞어 사용해도 중복 연결이나 의도하지 않은 다음 시작점이 생기지 않는다.

독립 검증: 누름·이동·놓음만 전송한 뒤 미리보기와 연결 요청 횟수·끝점을 확인한다. 뒤따르는 클릭을 추가해도 횟수가 증가하지 않아야 한다.

### 경계 조건

- 빈 공간·같은 요소·미니맵·캔버스 외부에는 연결을 추가하지 않는다.
- 우클릭 패닝은 연결 선택으로 처리하지 않는다.
- 취소·모드 전환·모델 교체 후 이전 제스처의 놓음은 무효다.
- 읽기 전용·오류 모델에는 연결을 추가하지 않는다.
- 확대·축소 및 화면 이동 후에도 놓은 위치의 모델 좌표를 사용한다.

## 요구사항

- FR-001: 유효한 왼쪽 누름 뒤 놓음에서 Wire 시작점 또는 끝점을 선택하며 이동 거리와 클릭 이벤트 유무에 의존하지 않는다.
- FR-002: 하나의 누름·놓음과 후속 클릭은 선택을 정확히 한 번만 처리한다. 정상 클릭과 기존 단독 클릭 입력도 유지한다.
- FR-003: 무효 위치·권한·모델 상태·취소·모드 전환·모델 교체·우클릭에는 연결 요청을 보내지 않는다.
- FR-004: 놓은 위치의 모델 좌표와 기존 스냅·미리보기·동일 요소 연결 제한·계속 추가 모드를 유지한다.

### 주요 개체

- Wire 선택 제스처: 유효한 왼쪽 누름 여부와 놓음 처리 상태.
- 연결 초안: 선택한 시작 요소 및 끝 요소와 각 모델 좌표.

## 성공 기준

- SC-001: 클릭 이벤트 없는 시작·끝 선택에서 올바른 연결 요청이 정확히 한 번 발생한다.
- SC-002: 후속 클릭과 연속 입력에서도 요청 중복이나 불필요한 다음 시작점 선택이 없다.
- SC-003: 무효 입력과 취소·전환·모델 교체 회귀 검증이 통과하고 확대율에 따른 끝점 좌표가 일치한다.

## 가정 및 명확화

질문 0개. 사용자가 놓음 기반 처리와 중복 방지 보완을 승인했다. 두 번 선택하는 기존 연결 흐름을 유지하며 한 번의 드래그로 양 끝점을 동시에 생성하는 기능은 추가하지 않는다. 범위·상호작용·경계·품질·의존성·용어·완료 기준에 중대한 모호성은 없다.
