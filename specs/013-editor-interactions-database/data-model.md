# 데이터 모델

- 드래그: 후보(press 좌표·원본) → 활성(임계치 이상) → 확정/취소. 활성 이후 click은 차단하며 새 press로 해제한다.
- 괄호: 렉서상 SYMBOL인 괄호의 오프셋 쌍. 주석·문자열은 제외하며 테마의 강조 속성을 사용한다.
- 메타데이터: Oracle 객체 키는 OWNER와 이름이다. catalog는 null이고 schema는 OWNER다. 컬럼은 COLUMN_ID 순서와 중복 제거를 유지한다.
- 연결 테스트: 선택한 DataSourceDraft의 복제본과 비밀번호 선택 정책을 입력으로 하고 성공/실패/취소를 결과로 한다. 영속 상태는 변경하지 않는다.
