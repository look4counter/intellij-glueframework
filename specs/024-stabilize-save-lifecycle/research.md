# 조사 결과

- 결정: 자동 생성은 미저장 출력 문서를 거부한다. 근거: 현재 save는 setText와 saveDocument로 수동 편집을 소실시킨다. 대안인 자동 병합은 안정화 범위를 넘고, 무조건 덮어쓰기는 변경 보존에 어긋난다.
- 결정: document.isWritable을 별도로 검사한다. 근거: 파일 쓰기 가능 여부와 문서 읽기 전용 상태는 독립적이다.
- 결정: 기존 오류 알림과 직접 편집 충돌 보호를 재사용한다. 근거: ServiceDiagramAdapter.validate는 문서 stamp 변경을 거부하고 rollback은 projection을 초기화한다.
- 결정: 기존 캐시 기반 직접 컴파일·JUnit 실행을 Gradle 실패 시 보조 검증으로 사용한다. 근거: 이전 검증에서 IDE ZIP 의존성이 누락됐다. 정상 빌드와 동등하다고 보고하지 않는다.
- 미해결 기술 질문 없음. 새로운 기술 선택 없이 로컬 구현을 조사했다.
