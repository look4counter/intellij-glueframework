# 실시간 정렬 보조선과 스냅

## 결정

최초 검토 이후 사용자가 구현을 승인했다. 놓을 때만 붙이는 초기 제안을 대체하여 드래그 중부터 정렬 위치에 붙고 보조선을 표시한다.

## 동작

- 선택하지 않은 Child의 좌우·상하 변과 중심을 대상으로 선택 영역의 변·중심을 맞춘다. 축별 가장 가까운 5px 이내 후보를 사용하며 동률은 모델 순서로 결정한다.
- 다중 선택은 하나의 경계와 공통 이동량을 사용하여 상대 간격을 유지한다. 선택한 Child는 모두 정렬 대상에서 제외한다.
- Activity 좌우 너비 조절은 움직이는 변의 정렬 및 다른 Activity와 같은 너비를 지원한다. 반대 변·높이는 고정하며 선택 Activity들의 공통 너비 변화량과 최소 너비 16px를 유지한다.
- Alt를 누르면 즉시 스냅·보조선이 해제되고 원래 마우스 이동량으로 돌아간다. Alt를 놓으면 다시 계산한다. 이동 시 같은 간격 맞춤도 아래 기준으로 제공한다.

## 구조와 보호

DiagramAlignment는 순수 좌표 계산이고 Canvas.previewChildDrag는 dragBase·dragAnchor에서 매번 원래 이동량을 다시 계산한다. 따라서 스냅 위치가 누적되지 않는다. release도 최종 좌표와 Alt 상태로 같은 계산을 사용하며 클릭만 한 경우 계산하지 않는다.

기존 onNodesMoved/onNodesResized와 editNodes 저장 명령을 재사용하여 한 번의 Undo/Redo를 유지한다. State 접점·Wire 참조는 DiagramEdits.relocateNodes를 재사용한다. Esc·Source 교체·읽기 전용 전환·release는 임시 보조선을 제거한다.

보조선은 모델 좌표에서 그리며 미니맵 프레임을 제외한다. 미니맵 자체는 스냅된 미리보기 도형을 반영한다. 후보 Child는 제스처 시작 때 수집한다. 변·중심은 대상 수에 비례해 비교하고, 같은 간격은 축별 정렬 후 인접 쌍을 비교하여 O(n log n)으로 계산한다.

## 검증

ModelDiagramAlignmentTest에서 임계치 경계·이탈·복귀·음수·집합 중심·빈 대상·같은 너비·좌우 조절·최소 너비·Alt·최종 release·클릭 무변경·읽기 전용·Source 교체·Esc·한 번의 Undo/Redo를 검증한다. 기존 정확한 마우스 이동 테스트는 Alt 우회로 검증한다. build/reports/model-alignment-guides.png에서 점선과 미니맵의 보조선 제외를 확인한다.

## 같은 간격 맞춤

선택 영역과 공통으로 겹치는 가로 줄 또는 세로 열의 인접한 두 Child를 기준으로 한다. 두 요소 사이에 놓아 양쪽 외곽 간격을 같게 맞추고, 앞·뒤에 놓아 기준 간격을 반복한다. 기준 Child가 겹치거나 선택 영역을 넣을 공간이 부족하면 해당 후보를 제외한다. 다른 대상과 겹치는 배치도 제외한다. State도 20×20 외곽 경계를 사용한다.

거리 보정은 5px 이내에서 기존 정렬과 경쟁한다. 절대 보정량이 작을수록 우선하고 동률은 기존 정렬을 우선한다. 같은 보정 위치에서 두 조건을 모두 만족하면 간격 치수선을 함께 표시한다. 가이드는 같은 두 거리의 치수선·화살표·끝 눈금과 px 수치를 보여준다. 반 픽셀 좌표는 유지하며 표시만 소수 한 자리로 정리한다.

다중 선택은 전체 경계를 하나의 요소처럼 사용한다. Alt·Esc·Navigation·Source·읽기 전용·한 번의 Undo/Redo는 기존 Canvas 제스처를 재사용한다. 너비 조절에는 새 간격 후보를 적용하지 않는다. build/reports/model-equal-spacing.png에서 다중 선택과 두 100px 간격 표시를 확인한다.
