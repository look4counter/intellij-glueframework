# 데이터와 상태

- 토큰: 원문 위치·끝 위치·문자열·식별자 여부·인용 여부를 가진다. 주석·공백은 범위 인덱스에서 제외한다.
- 쿼리: CTE 환경과 집합 연산으로 구분한 SELECT 블록을 가진다. 문장은 세미콜론으로 분리한다.
- 블록: 원문 범위·구역 토큰·관계·SELECT 출력 목록·상관 쿼리의 바깥 범위를 가진다.
- 관계: 실제 테이블 경로 또는 CTE·파생 쿼리, 별칭과 선택적 컬럼 이름 목록을 가진다.
- CTE: 이름·선택적 명시 컬럼·본문 쿼리를 가진다. 동일 이름은 안쪽 범위가 우선하고 순환 컬럼 추론은 중단한다.
- 완성 결과: 테이블·컬럼·일반·금지 문맥, 키워드 허용 여부와 후보 목록을 가진다.
- 후보: 실제 삽입 문자열, 원래 검색 이름과 종류·출처 안내를 가진다. 동일 삽입 문자열은 합친다.

모든 구조는 한 번의 자동완성 요청에 속하며 문서·메타데이터를 수정하지 않는다.
