# 자동완성 계약

- FROM·JOIN: 메타데이터 테이블과 현재 범위 CTE. 스키마와 점을 입력하면 해당 스키마 테이블만 제공한다.
- SELECT·WHERE·ON·GROUP BY·HAVING·ORDER BY: 현재 범위 관계의 컬럼. ORDER BY·GROUP BY에는 확인 가능한 SELECT 출력 이름도 제공한다. 관계를 확인하지 못하면 캐시의 컬럼을 사용한다.
- 별칭과 점: 그 관계의 컬럼만 제공하고 삽입은 컬럼 부분에 한정한다. 모르는 별칭에는 일반 컬럼·키워드를 제공하지 않는다.
- 중복 컬럼: 서로 다른 관계의 동일 컬럼은 관계 한정자를 포함해 삽입하고 원래 컬럼 접두어로 검색할 수 있어야 한다.
- CTE: 명시 목록을 우선하고 직접 SELECT 컬럼·AS 또는 암시적 출력 별칭·확인 가능한 별표를 사용한다. 일반 CTE 본문에는 이후 정의가 보이지 않는다. 중첩 범위는 안쪽을 우선한다.
- 파생 테이블: 출력 컬럼만 노출하며 내부 테이블 별칭을 외부에 노출하지 않는다.
- 키워드: 기존 키워드 목록과 접두 대소문자 무시 검색을 유지하되 한정자 뒤에는 컬럼·테이블 이름만 제공한다.
- 보호·복구: 따옴표·주석·숫자·파라미터·읽기 전용 보호를 유지한다. 알 수 없는 SQL은 기존 일반 후보로 복구하고 자동완성 중 DB 조회와 쓰기는 하지 않는다.
- 정렬: 종류를 먼저, 그룹 안에서는 대소문자 무시 ABC순을 사용한다. 컬럼 문맥의 일반·출력 컬럼은 최상위 한 그룹이고 FROM·JOIN의 CTE·테이블도 최상위 한 그룹이다. 키워드는 그 뒤에 표시한다.
- 일반 후보의 종류 순서는 컬럼·CTE·테이블·키워드다. 여러 종류가 병합된 동일 이름은 가장 앞선 순위를 사용하며 항목은 중복하지 않는다. 접두어 필터·조회 이름·삽입 동작은 유지한다.
