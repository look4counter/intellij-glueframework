# 데이터 모델

변경문 범위는 테이블·별칭·CTE·파생 쿼리의 소스를 해석하는 문맥이다. SELECT 출력은 기존 슬롯 기반 입력·소비자 관계를 사용한다.

현재 문장의 변경문 컬럼 참조 전체를 미리 수집하고 동일 SqlSource·동일 컬럼 키에 연결한다. 테이블명·별칭·CTE 선언 토큰은 컬럼 참조에서 제외한다. 물리 테이블 출처는 선언 위치를, CTE·파생 소스는 기존 SELECT 출력 경로를 사용한다. SET 좌변·INSERT 대상의 한정자가 없으면 대상 소스를 사용한다. 대입 좌우·상수 값을 연결하는 쓰기 계보는 만들지 않는다.

커서가 SELECT 출력 expression의 값 토큰에 있으면 해당 출력 슬롯을 시작 노드로 사용한다. 따라서 같은 출력의 별칭과 문자열·숫자·파라미터·CASE 값에서 시작한 전체 경로가 같다. 변경문 참조 선택은 해당 참조를, 값 선택은 해당 출력 슬롯을 selectedOffset·그래프 선택 ID로 사용한다. 모든 상태는 분석 요청 동안만 유지한다.

## 후속 정렬 모델

정렬 그룹은 한 절의 행별 첫 등호 토큰과 출력 열의 집합이다. 일반 괄호는 그룹을 공유하고 서브쿼리는 자체 그룹을 갖는다. 영속 설정 alignWhereEquals의 자료형과 기본값은 유지한다.
