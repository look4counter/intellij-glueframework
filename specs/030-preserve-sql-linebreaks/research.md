# 조사 결과

- 기존 포매터는 SqlFormattingToken에 원본 start/end를 보관하지만 Writer.line이 무조건 새 줄을 만들고 공백 토큰을 버린다. Writer에서 원본 경계를 소비하면 구문 분석을 유지하면서 사용자의 행 구성을 보존할 수 있다.
- 복합 키워드는 하나의 문자열로 출력하므로 GROUP과 BY 사이 줄바꿈이 사라진다. 각 토큰을 따로 출력해야 한다.
- 기존 선택 포매팅은 포매터가 제거한 경계 줄바꿈을 다시 붙인다. 원문 보존 후에는 이를 제거해야 중복되지 않는다.
- 주석 줄에는 원본 들여쓰기와 후행 공백이 이미 포함된다. 토큰 뒤 원본 소비 위치를 해당 줄 끝으로 옮겨 이중 출력과 빈 줄 중복을 방지한다. 미해결 기술 질문은 없다.
