# 조사 결과

## 결정

createChild 및 editWire와 동일한 deferModelEdit를 재사용한다. createWire는 commitDocument 이전에 이 가드가 누락되어 있다. 외부 API 조사 없이 저장소 구현과 기존 테스트를 근거로 결정했다.

## 근거와 대안

UI 이벤트 스레드라는 사실만으로 쓰기 의도 잠금이 보장되지 않는다. 고정 시간 지연이나 PC 속도별 분기는 권한을 보장하지 못하므로 채택하지 않는다. 변경 가능한 moveStamp를 지연 시 다시 읽지 않고 expectedStamp로 캡처한다.

## 선택 편집 결정

삭제·복사 요청은 문서 stamp 및 선택 값 스냅샷을 캡처하고 변경되면 취소한다. 붙여넣기는 문서 stamp와 클립보드 객체를 검증한다. 현재 선택을 지연 시 그대로 사용하는 대안은 다른 요소를 삭제·복사할 수 있으므로 제외한다. 기존 provider의 활성화 조건을 실행 시 재사용한다.
