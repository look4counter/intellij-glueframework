# Wire 추가 입력 계약

노드 시작점과 다른 노드 끝점을 클릭하거나 드래그로 놓아 연결한다. 잠금 없는 UI 이벤트에서는 문서를 즉시 수정하지 않고 안전 문맥에서 한 번 적용한다. 결과는 wire 요소 하나와 시작 output·끝 input 참조다. 실행 취소 한 번으로 원문을 복구한다. 예약 후 모드 취소·원문 변경·읽기 전용·폐기는 원문을 보존한다.

삭제·복사·붙여넣기도 잠금 없는 provider 호출을 지원한다. 지연 중 대상 문서나 선택이 바뀌면 다른 대상을 처리하지 않는다. 읽기 전용 복사는 허용하고 삭제·붙여넣기는 금지한다. 클립보드가 바뀌면 예약된 붙여넣기는 취소한다.
