# 기능 명세: 설정 속성 편집 유지

**작성일**: 2026-10-27
**상태**: 명확화 완료
**요청**: Settings의 Properties 편집이 주기적으로 종료되는 문제를 수정한다.

## 사용자 시나리오와 검증

### 사용자 이야기 1 — 중단 없이 속성 편집 (우선순위: P1)

사용자는 GlueModelEditor의 Activity 프리셋 Properties에서 키와 값을 계속 입력하고 적용한다.
주기적인 변경 확인 때문에 입력을 다시 시작해야 하는 불편을 없앤다.

**독립 검증**: 셀 편집 중 변경 여부를 반복 확인하고 편집 상태와 입력값을 검사한다.

**인수 시나리오**:

1. 저장된 속성의 키 또는 값을 편집할 때 변경 확인이 반복되어도 편집과 선택 영역이 유지된다.
2. 아직 확정하지 않은 입력도 변경 여부에 반영되며 원래 값으로 되돌리면 변경 없음으로 표시한다.
3. 편집 중 Apply를 누르면 최신 입력을 저장하고, Reset하면 저장된 값으로 복원한다.
4. 프리셋을 전환하면 입력한 값이 원래 프리셋에 보존된다.

### 경계 조건

- 프리셋이 없거나 편집 중인 셀이 없어도 변경 여부를 정상 판정한다.
- 조회만으로 저장된 설정이나 편집 테이블의 확정 데이터를 바꾸지 않는다.
- 색상·이름·설명·경로·체크박스의 기존 적용 동작을 유지한다.

## 요구사항

### 기능 요구사항

- **FR-001**: 변경 여부 조회는 셀 편집을 종료하거나 화면을 재생성하지 않아야 한다.
- **FR-002**: 미확정 키·값 입력을 포함하여 변경 여부를 판단하되 조회에 따른 데이터 변경은 없어야 한다.
- **FR-003**: Apply와 프리셋 전환은 최신 셀 입력을 확정하고 Reset은 미적용 입력을 복원해야 한다.
- **FR-004**: 다른 프리셋과 기존 설정 필드는 그대로 보존해야 한다.

### 주요 개체

- 프리셋: 이름·속성 목록·설명·배경색·글자색을 가진 설정 항목이다.
- 미확정 셀 입력: 편집 중인 속성의 키 또는 값이며 저장된 값과 구별한다.

## 성공 기준

- **SC-001**: 키와 값 각각에 대해 변경 확인을 10회 반복해도 같은 셀의 편집과 선택 영역이 유지된다.
- **SC-002**: 미확정 변경·원래 값 복원·Apply·Reset·프리셋 전환의 회귀 검증이 모두 통과한다.

## 가정 및 명확화

사용자가 수정을 승인한 대상은 앞서 원인을 확인한 GlueModelEditor Properties이다.
GlueQueryEditor의 DataSource 설정과 컬러피커 동작은 범위에 포함하지 않는다.
명확화 검토 결과 범위·데이터·사용 흐름·예외·성공 기준에 중대한 모호함은 없으며 추가 질문은 없다.
기존 설정·속성 회귀 테스트에 자동 검증을 추가한다.
