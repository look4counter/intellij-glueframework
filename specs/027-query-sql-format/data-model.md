# 데이터와 상태

포매팅 토큰은 원문·어휘 종류·시작/끝 위치와 괄호 연결을 가진다. 공백만 새로 생성하며 문자열·주석·인용 식별자 토큰은 원문을 보존한다.

작성기는 현재 열·쿼리 시작 열·SELECT T 열·목록 표현식 열과 CASE 스택을 가진다. CTE·서브쿼리에 진입하면 시작 열을 4 늘리고 복귀하면 바깥 열을 복원한다.

포맷 결과는 SQL 또는 거부 사유다. UI 요청은 선택 대상 포인터·선택 세대와 연결되며 지연 중 선택 변경·폐기·쓰기 불가이면 실행하지 않는다. 성공은 Source XML의 단일 수정→Design 버퍼 갱신→저장·Undo/Redo 순서로 반영한다.
