# 설계 조사

- 결정: 첫 패닝 시 화면 주변까지 한 번 캡처한다. 기존 미니맵 이미지 처리 방식을 참고한다.
- 근거: 이동 중 도형·텍스트 재렌더링을 제거한다. 화면 전체 모델 캡처는 메모리 비용으로 제외한다.
- 대안: 이벤트마다 재생성은 목적과 충돌한다. 영역 밖은 기존 벡터 렌더링으로 보충한다.
- 무효화: 모델·외형·폰트·확대율·화면 크기 변경 시 정상 렌더링으로 복귀한다.
- 검증 중 확인: 미니맵이 화면 영역을 포함해 축척을 변경하면 전체 모델을 다시 그린다. 패닝 중에는 미니맵 배경의 투영을 고정하고 현재 화면 사각형만 갱신한다. 종료 후 자동 맞춤으로 복귀한다.
- 실제 픽셀 재현 결과: 기본 배율에서 내부 원의 가로 중심은 약 29.995, 외부 윤곽은 30.513이었다. 외부 윤곽이 오른쪽 아래로 정규화되어 내부가 상대적으로 왼쪽 위에 보인다. 종료 상태만 순수 윤곽 좌표로 그린다.
