# 데이터 모델

이동 스냅샷은 이미지, 논리 화면 영역, 기준 화면 오프셋, 확대율과 화면 크기를 보관한다. 첫 이동에 생성하며 해제·취소·모델 변경·컴포넌트 제거 시 폐기한다. 생성 시도 여부는 제스처 동안 유지해 반복 생성하지 않는다.

변경 비교 캐시는 편집본 객체, 편집본 수정 시각, 기준 모델 객체, 비교 결과를 보관한다. 어댑터당 마지막 결과 하나만 유지하며 편집본·기준 모델 교체, 내용 수정, 보류 표시 재설정, 롤백·적용 시 갱신하거나 폐기한다.
미니맵 현재 투영은 모델과 현재 화면의 합집합으로 계산한다. 스냅샷 시작 투영은 배경 좌표계이며 배율 비율과 오프셋으로 현재 투영에 변환한다.
패닝 기준 범위는 시작 전체 범위의 각 축에 반 범위의 여백을 추가한 사각형이다. 시작과 종료 시 투영 캐시를 무효화하며 모델 경계 자체는 유지한다.
배율 유지 보완: 두 배 여백과 현재 투영 자동 맞춤을 폐기한다. 시작 투영의 배율·오프셋을 유지하고 현재 modelViewport만 갱신한다. 표시 사각형은 영역과의 교집합이며 각 축 최소 2픽셀을 유지한다.
균등 여백·요소 이동 보완: 콘텐츠 여백은 네 방향 모두 8픽셀이다. 현재 투영 오프셋은 시작 오프셋에 시작·현재 모델 화면 중심 차이 × 시작 배율 ÷ 2를 더한다. 배율과 모델 좌표는 불변이며 이전 오프셋 고정 정책을 대체한다.
자동 배율 보완: 현재 overviewBounds는 모델·현재 화면의 합집합이다. 표시 중심은 시작 전체 범위 중심에 현재·시작 화면 중심 차이의 절반을 더한다. 배율은 각 축의 최대 반경 두 배에 콘텐츠 크기를 나눈 값과 0.5 중 최솟값이다. 오프셋은 콘텐츠 중심에서 표시 중심×배율을 뺀 값이다.
