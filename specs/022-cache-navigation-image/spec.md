# 기능 명세: 화면 이동 이미지 재사용

작성일: 2026-11-06. 상태: 검증 완료.
입력: 화면 이동 시작 시 한 번 이미지를 만들고 이동 중 재사용하며 종료하면 정상 렌더링한다.

## 사용자 시나리오 및 검증

### 사용자 이야기 1: 부드러운 화면 이동 (우선순위 P1)

사용자는 우클릭 화면 이동 시 기존 그림을 재사용한다.
독립 검증: 연속 패닝 후 동일 위치의 정상 렌더링과 비교한다.

1. 이동 시작 시 주변 영역까지 그림을 한 번 준비하고 이후 위치만 바꾼다.
2. 종료·취소 시 현재 위치에서 원래 품질로 다시 그린다.
3. 준비 영역 밖으로 이동해도 요소가 누락되지 않는다.

### 경계 조건

화면 크기·확대율·모델·외형 변경 시 오래된 이미지를 쓰지 않는다. 큰 화면에서 메모리를 제한하고 준비 불가 시 기존 렌더링을 사용한다.

## 요구사항

- FR-001: 화면 이동마다 이미지를 최대 한 번 준비하고 재사용한다.
- FR-002: 종료·취소 시 이미지를 해제하고 정상 렌더링으로 복귀한다.
- FR-003: 준비 영역 밖은 정상 렌더링으로 보충한다.
- FR-004: 미니맵과 좌표는 이동 중에도 현재 상태를 표시한다.
- FR-005: 모델이나 화면 조건 변경 시 오래된 이미지 대신 정상 렌더링하고 저장량을 제한한다.

### 주요 개체

- 이동 이미지: 기준 위치와 주변 영역의 일시적인 그림.
- 화면 이동: 시작·진행·종료·취소 상태.

## 성공 기준

- SC-001: 준비 영역 안의 연속 이동 시 이미지 준비 횟수는 1회이고 요소를 다시 그리지 않는다.
- SC-002: 종료 후 동일 좌표의 정상 렌더링과 화면이 일치한다.
- SC-003: 준비 영역을 넘어도 노드와 연결선이 누락되지 않는다.

## 가정 및 명확화

사용자가 시작 시 한 번 준비하고 종료 시 정상 렌더링하는 방식을 확정했다. 추가 질문이 필요한 중대한 모호성은 없다. 우클릭 패닝만 대상이며 저장 오류 조사는 범위 밖이다.

## 패닝 표시 경계 수정

- FR-006: 패닝 중 현재 화면 표시 사각형과 선 두께는 미니맵 콘텐츠 영역 안에 머물러야 한다. 패닝 중 현재 범위에 맞춰 배율과 요소 이동을 반영하며 현재 화면 표시의 영역 밖 부분은 잘라낸다. 종료 후 자동 맞춤한다.
- SC-004: 상하좌우로 큰 패닝을 수행해도 파란 표시 픽셀이 콘텐츠 영역 밖에 나타나지 않고 영역 안에서는 표시가 유지된다.
- 명확화: 이미지 재사용 성능을 유지하면서 표시 위치를 경계로 제한한다. 추가 질문이 필요한 모호성은 없다.

## 종료 상태 중심 보정

- FR-007: FinalState의 안쪽 원과 바깥 원은 동일한 중심을 사용해야 한다. 원의 기존 지름은 유지한다.
- SC-005: 지름 20인 바깥 원과 지름 15인 안쪽 원의 중심 좌표 차이는 두 축 모두 0이다.
- 명확화: 사용자가 보고한 종료 상태의 시각적 중심 문제를 기존 캔버스 렌더링 수정에 포함한다. 추가 모호성은 없다.

## 종료 상태 실제 렌더링 중심 검증

- FR-008: FinalState 안쪽 채움과 바깥 윤곽은 화면에 그려진 결과에서도 같은 중심을 사용해야 한다. Java2D의 선 정규화로 윤곽만 이동하지 않아야 한다.
- SC-006: 기본 배율과 고해상도 렌더링에서 두 원의 검은 픽셀 중심 차이는 각 축 0.2 장치 픽셀 이내이다.
- 명확화: 이전 수정은 수학 좌표만 검증했다. 이번에는 실제 그리기 결과를 검증한다. 별도 사용자 결정은 필요하지 않다.

## 패닝 중 주기적인 상태 조회 지연 개선

- FR-009: 화면 이동처럼 내용을 바꾸지 않는 조작 중에는 동일한 편집 내용의 변경 여부를 반복해서 전체 비교하지 않는다.
- FR-010: 화면 이동 중 붙여넣기 가능 여부 조회는 외부 클립보드 읽기를 수행하지 않으며 종료 후 정상 조회한다.
- SC-007: 동일한 서비스 편집본에 대한 변경 상태 조회 100회가 하나의 비교 결과를 재사용하고, 내용 수정·되돌림·롤백 이후에는 정확한 결과를 반환한다. 회귀 테스트로 검증한다.
- SC-008: 패닝 중 붙여넣기 가능 여부는 거짓이며 종료 후 기존 붙여넣기 기능이 유지된다.
- 명확화: 주기적인 끊김의 후보인 UI 상태 조회 비용을 개선한다. 렌더링 캐시와 저장 의미는 유지한다. 실제 IDE 체감 개선은 별도로 확인해야 하며 모든 지연 원인의 제거를 보장하지 않는다. 추가 사용자 결정이 필요한 모호성은 없다.

## 패닝 중 미니맵 위치 표시 동기화

- 사용자 이야기 1 보완: 사용자는 우클릭을 누른 채 이동하는 동안 미니맵의 파란 현재 화면 표시가 실제 위치를 따라가는 것을 확인한다.
- FR-011: 작은 모델과 큰 화면에서도 패닝 중 현재 화면 표시 위치가 갱신되어야 한다. 미니맵 배경 이미지는 재사용하며 모델 좌표와 저장 상태는 유지한다.
- SC-009: 상하좌우 연속 패닝의 각 중간 프레임에서 표시 픽셀이 이전 프레임과 달라지고 요소와 현재 화면 표시의 보이는 부분이 미니맵 콘텐츠 안에 그려진다. 반대로 이동하면 시작 표시로 돌아오고 종료 시에도 위치가 유지된다.
- 명확화: 커서는 미니맵의 파란 현재 화면 사각형으로 해석한다. 패닝 중 배율은 현재 표시 범위에 맞추고 표시 사각형의 겹치는 부분으로 이동을 나타낸다. 기능·데이터·상호작용·품질·의존성·경계·제약·용어·완료 기준을 검토했으며 추가 질문이 필요한 중대한 모호성은 없다.

## 패닝 중 미니맵 배율 유지

- FR-012: 패닝 시작과 진행 중에는 시작 순간의 미니맵 배율을 유지하며 이동 중에는 표시 범위에 맞춰 조정하면서 모델 표시 위치는 패닝을 따라 이동한다. 파란 화면 표시는 실제 이동을 따라가며 영역 밖 부분은 잘라낸다. 완전히 벗어나면 가장자리에 최소 표시를 남긴다. 종료 후 일반 자동 맞춤으로 복귀한다.
- SC-010: 이동량 0인 패닝 시작 전후의 배율·오프셋·도형 표시가 동일하고, 네 방향 연속 및 큰 이동 중에는 표시 범위에 맞춰 배율을 조정하며 요소와 현재 화면 표시의 상대 이동이 실제 패닝과 일치한다. 기존 이미지 재사용과 화면 표시 이동 검증이 통과한다.
- 명확화: 사용자의 축소 금지 요청에 따라 이전의 두 배 여백·이동 중 자동 맞춤 정책을 대체한다. 시작 순간 배율 유지를 우선하고 이동 중에는 현재 화면 전체를 포함하도록 배율을 조정한다. 범위·데이터·상호작용·품질·경계·용어·완료 기준을 검토했고 추가 질문은 없다.

## 미니맵 균등 여백과 요소 이동

- FR-013: 미니맵 외곽과 콘텐츠 사이 상하좌우 여백을 동일하게 맞춘다.
- FR-014: 패닝 중 미니맵 요소들이 메인 화면의 요소와 같은 방향으로 이동해야 한다. 패닝 시작 순간 배율은 유지하고 이동 중에는 조정하며 파란 화면 표시와 요소의 상대 이동도 실제 화면 위치를 나타내야 한다. 배경 이미지는 재사용하고 모델 좌표는 바꾸지 않는다.
- SC-011: 일반 화면과 스크롤된 화면의 미니맵에서 상하좌우 여백이 모두 8픽셀이다.
- SC-012: 네 방향 연속 패닝에서 요소 표시 픽셀과 파란 표시가 갱신되고 두 표시의 상대 이동량이 화면 이동량에 비례한다. 원점 복귀·종료·시작 배율 유지·재렌더링 0회 검증이 통과한다.
- 명확화: 요소 이동은 미니맵 안의 도형 표시 이동으로 해석한다. 시작 순간의 불필요한 축소 금지는 유지하고 이동 중 자동 확대·축소는 허용한다. 이전 도형 위치 고정 정책은 대체한다. 범위·상호작용·경계·성공 기준을 검토했으며 추가 질문이 필요한 모호성은 없다.

## 패닝 중 미니맵 자동 확대·축소

- FR-015: 패닝 중 요소 이동과 함께 미니맵 배율도 현재 모델과 화면 영역을 모두 표시하도록 조정한다. 이동량 0인 시작 순간에는 배율을 변경하지 않는다. 원래 위치로 돌아오면 원래 배율로 복귀한다. 캐시 배경 이미지를 재사용하고 모델 및 메인 화면의 확대율은 변경하지 않는다.
- SC-013: 네 방향의 큰 패닝에서 전체 모델과 현재 화면이 미니맵 안에 들어오며 배율이 시작보다 작아진다. 원점으로 되돌아오는 중에는 요소가 다시 커지고 원점에서 시작 투영과 일치한다. 실제 요소 픽셀 크기 변화와 이미지 재사용을 회귀 검증한다.
- 명확화: 사용자가 패닝 위치에 맞춘 미니맵 요소 자동 확대·축소로 확정했다. 메인 화면 줌 조작의 변경은 범위 밖이다. 이전 이동 중 고정 배율 정책을 대체하며, 시작 시 강제 여백으로 축소하지 않는 정책은 유지한다. 기능·상호작용·경계·검증 기준을 검토했다.
