# 화면 이동 계약

우클릭 패닝의 좌표와 취소 동작을 유지한다. 이미지에는 모델과 선택 표시만 포함한다. 미니맵과 좌표는 매번 최신 상태로 그린다. 캡처 영역 밖은 원래 방식으로 그리며 종료 시 이미지 사용을 중단한다.
패닝 중에도 자동 맞춤한다. 배경 이미지는 시작 투영에서 재사용하고 현재 화면 표시는 현재 투영에서 그린다.
작은 이동도 표시되도록 패닝 기준 범위에 여백을 둔다. 종료 시 여백 없는 일반 자동 맞춤으로 복귀한다.
배율 유지 보완: 패닝 시작·진행 시 배율과 도형 위치는 고정한다. 현재 화면의 영역 밖 부분은 잘라 표시하고 완전히 벗어나면 경계에 최소 표시를 남긴다. 종료 후 자동 맞춤한다.
균등 여백·요소 이동 보완: 콘텐츠 여백은 상하좌우 8픽셀이다. 패닝 중 배율은 고정하고 요소는 화면 이동 방향으로, 파란 표시는 반대로 움직인다. 표시 중심은 시작·현재 화면 중심의 중간을 사용하며 캐시 이미지는 평행 이동해 재사용한다.
자동 배율 보완: 패닝 진행 중 모델과 현재 화면 전체를 포함하도록 배율을 갱신한다. 이동량 0인 시작과 원점 복귀는 원래 투영을 유지한다. 메인 줌과 모델 데이터는 변경하지 않는다. 이전 이동 중 고정 배율 정책을 대체한다.
