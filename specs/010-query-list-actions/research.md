# 조사 결과

## 결정과 근거

기존 QueryDesignEditor에는 목록 구조 편집 기능이 없다. 플랫폼의 Add·Remove·Copy·MoveUp·MoveDown 아이콘을 재사용한다. 연구 에이전트가 로컬 SDK에서 존재를 확인했다.

쓰기 의도 잠금과 TransactionGuard의 안전 문맥을 확보한 뒤 문서를 커밋하고 구조를 변경한다. 단일 WriteCommandAction을 사용한다. 복제와 이동은 태그 전체를 복사하여 알 수 없는 내용과 CDATA를 유지한다. 이동 후 삭제된 기존 태그 대신 새 포인터로 선택을 유지한다.

## 대안

전체 XML 재작성은 주석과 서식을 잃을 수 있어 제외했다. 텍스트 버튼은 사용자 아이콘 요청에 맞지 않아 제외했다. 삭제 확인창은 즉시 삭제 요청과 실행 취소 지원에 따라 추가하지 않는다.
