# 기능 명세: 파일 형식 표시 이름 충돌 수정

**작성일**: 2026-10-24
**상태**: 명세 검증 완료
**입력**: 두 Glue 파일 형식의 표시 이름이 XML로 중복되는 오류를 수정한다.

## 사용자 시나리오 및 검증

### 사용자 스토리 1 — 파일 형식 구분 (우선순위: P1)

사용자는 플러그인을 로드하고 파일 형식 설정에서 Glue SQL, Glue UML AD, XML을 구분할 수 있다.

**우선순위 이유**: 파일 형식 이름 중복 오류를 제거한다.
**독립 검증**: 등록된 세 파일 형식의 표시 이름을 비교하고 기존 편집 동작을 확인한다.

**인수 시나리오**:

1. 플러그인을 로드하면 Glue SQL과 Glue UML AD의 표시 이름은 서로 다르고 기본 XML과도 다르다.
2. 기존 확장자의 파일을 열면 기존 XML 편집·저장 동작이 유지된다.

### 경계 사례

- 기본 XML 파일 형식과의 표시 이름 충돌도 방지한다.
- 빈 Glue 파일의 편집과 저장도 유지한다.

## 요구사항

### 기능 요구사항

- **FR-001**: Glue SQL과 Glue UML AD는 각각 해당 이름을 표시하여 서로 및 기본 XML과 구분되어야 한다.
- **FR-002**: 기존 파일 형식 식별자, 확장자 연결, 아이콘 및 XML 편집 기능을 유지해야 한다.

## 성공 기준

- **SC-001**: 세 파일 형식의 표시 이름 중 중복은 0개이다.
- **SC-002**: 기존 파일 연결 및 편집·저장 검증이 모두 통과한다.

## 가정

- 기존 이름인 Glue SQL과 Glue UML AD를 표시 이름에도 사용한다.
- 수정 범위는 표시 이름 충돌과 관련 검증으로 제한한다.
- 회귀 방지를 위해 기존 파일 형식 통합 테스트에 이름 유일성 검증을 추가한다.
