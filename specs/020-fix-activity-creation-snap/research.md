# 조사 및 결정

- 결정: createChild 진입 시 deferModelEdit로 위임한다. 근거: 현재는 TransactionGuard.isWritingAllowed만 검사하며 쓰기 의도 잠금과 EDT 검사가 빠져 있다. 속성 편집은 이미 같은 함수를 사용한다.
- 결정: 요청의 creationRevision을 검사한다. 근거: 예약 중 같은 종류를 다시 선택하거나 프리셋을 바꿔도 이전 입력을 추가하면 안 된다.
- 결정: DiagramAlignment.move를 새 Ghost에 적용한다. 근거: 기존 도형 이동과 같은 정렬·간격·허용 범위를 제공한다.
- 대안: paint마다 계산하면 마우스 이동과 무관한 그리기에서도 정렬 비용이 발생하므로 입력 때 보정 좌표를 저장한다.
- 결정: 안내선 및 거리 라벨의 이전·현재 범위도 부분 갱신에 포함한다. 근거: 기존 Ghost 부분 갱신 성능을 유지하면서 잔상을 없앤다.
- 미확정 사항 없음. 실제 오류 스택이 제공되지 않았으므로 발견한 잠금 누락을 자동 재현으로 검증한다.
