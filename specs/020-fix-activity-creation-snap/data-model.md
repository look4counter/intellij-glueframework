# 데이터 모델

- ChildCreationRequest: 기존 종류·좌표·프리셋·세대·요청 및 입력 식별자를 유지한다. 실행 전에 세대와 편집 가능 상태를 확인한다.
- 미리보기 원래 포인터 및 Alt 상태: 화면 좌표와 임시 우회 여부. 설정 변경 때 재계산한다.
- creationPoint: Snap 보정을 반영한 중심 모델 좌표. ghostNode의 위치와 확정 요청이 공유한다.
- alignmentGuides: 현재 보정 안내선. 모드 취소·이탈 시 비운다.

추가 요청은 접수 → 안전한 문맥으로 위임 → 재검증 → 원문 추가 및 갱신으로 전이한다. 모드 변경·폐기는 실행을 무효화한다. 영속 형식 변경 없음.
