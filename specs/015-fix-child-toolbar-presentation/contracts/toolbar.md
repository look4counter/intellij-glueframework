# 생성 툴바 계약

텍스트 버튼은 현재 종류나 프리셋을 표시하고 클릭하면 생성 모드를 전환한다. 화살표는 기존 종류·프리셋 메뉴를 연다. 읽기 전용에서는 두 컨트롤이 비활성화된다. 표시 갱신은 등록된 커스텀 컴포넌트를 보존한다. 서로 다른 에디터는 상태와 컴포넌트를 공유하지 않는다. 다른 툴바 버튼과 생성 동작에는 변경이 없다.

## 후속 표시 및 안내 문구

- 기본 Activity 표시 이름: Empty Activity.
- 생성 토글의 마우스 안내: Activity 추가. 프리셋과 종류에 관계없이 같은 문구를 사용한다.
- 종류 메뉴 및 선택 안내: Activity 선택.
- Wire·Snap·Orthogonal·Properties 마우스 안내: Wire 추가·정렬 토글·직각 Wire 토글·파일 속성.
- 기존 네 버튼의 이름·순서·동작과 등록 컴포넌트는 유지한다.
