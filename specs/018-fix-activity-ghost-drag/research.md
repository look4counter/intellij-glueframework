# 조사 및 결정

- 결정: 전체 화면 갱신 대신 미리보기의 이전·현재 화면 범위를 갱신한다.
- 근거: drawNode와 drawWire에는 이미 클립 검사가 있다. 전체 repaint 요청이 보이는 도형을 모두 다시 그리게 한다.
- 대안: 배경 이미지 캐시는 확대·축소와 고해상도 및 선택 상태 무효화 복잡성 때문에 채택하지 않는다.
- 결정: 추가 모드 mouseDragged를 조기 처리하고 놓기 거리 제한을 제거한다.
- 근거: 기존 드래그는 creationPressPoint를 처리하지 않아 미리보기 추적이 빠지고, release는 4픽셀 초과를 거부한다.
- 경계: 캔버스 내부와 미니맵 외부에서만 제출한다. 기존 모드 세대와 중복 클릭 억제를 유지한다.
- 미확정 기술 사항: 없음. 다른 컴퓨터에서의 프레임 시간은 재현 환경이 없어 단정하지 않는다.

## 회귀 검증 중 확인한 보완 사항

레이아웃 전 크기가 0인 캔버스는 입력 영역을 아직 판단할 수 없으므로 기존 합성 입력 동작을 유지한다. 실제 크기가 정해진 캔버스에는 표시 영역 검사를 적용한다. 기존 도형 드래그에서 남은 클릭 억제 상태는 추가 모드 전환 시 초기화하여 첫 추가 클릭이 무시되지 않도록 한다. FR-003의 정상 클릭 추가에 포함된다.
