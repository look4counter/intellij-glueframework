# 기능 명세: Activity 미리보기 이동 및 드래그 추가 개선

**작성일**: 2026-11-04
**상태**: 명세 검증 완료
**입력**: 다른 컴퓨터에서 빈 Activity의 Ghost 이동이 매우 느리고 드래그 후 추가되지 않는 문제를 해결한다.

## 사용자 시나리오 및 검증

### 사용자 이야기 1: 미리보기 이동 (우선순위: P1)

기존 다이어그램 위에서 빈 Activity 미리보기를 이동하고, 마우스를 누른 채로도 원하는 위치까지 옮긴다. 독립 검증은 기존 도형이 많은 화면에서 이동 전후 표시를 비교한다.

1. 추가 모드에서 마우스를 이동하면 미리보기가 따라오고 이전 위치에 잔상이 남지 않는다.
2. 누른 채 이동해도 미리보기가 따라오며, 이동만으로 원본 문서가 변경되지 않는다.

### 사용자 이야기 2: 드래그로 추가 (우선순위: P1)

사용자는 짧게 클릭하거나 드래그하여 놓은 위치에 Activity 하나를 추가한다. 독립 검증은 제출 횟수와 위치를 확인한다.

1. 4픽셀보다 멀리 드래그한 후 놓아도 마지막 위치에 하나가 추가된다.
2. 뒤따르는 클릭 이벤트가 있어도 중복으로 추가되지 않는다.

### 경계 조건

- 캔버스 밖이나 미니맵 위에서 놓으면 추가하지 않는다.
- 취소하거나 추가 종류를 바꾸면 진행 중 제스처는 무효다.
- 확대·축소 및 화면 이동 후에도 모델 좌표가 일치한다.

## 요구사항

- **FR-001**: 이동 및 드래그 모두 미리보기 위치를 갱신한다.
- **FR-002**: 미리보기 이동은 바뀐 영역만 갱신하여 전체 화면 그리기 부담을 줄인다.
- **FR-003**: 유효한 위치에서 놓으면 거리와 무관하게 정확히 한 번 추가한다.
- **FR-004**: 취소·미니맵·캔버스 외부·중복 클릭 보호를 유지한다.

### 주요 개체

- 미리보기: 종류, 모델 좌표, 화면상의 이전·현재 범위.
- 추가 제스처: 시작 지점, 모드 세대, 완료한 입력의 위치 및 시각.

## 성공 기준

- **SC-001**: 드래그·클릭·취소·영역 이탈 자동 검증이 모두 통과한다.
- **SC-002**: 2,000개 노드에서 미리보기 이동의 갱신 영역은 인접 이동 시 전체 화면보다 작고, 부분 갱신 결과는 전체 갱신 결과와 일치한다.

## 가정 및 명확성 검토

2026-11-04: 질문 0개. 사용자가 승인한 드래그 추가를 적용하며 프리셋과 다른 노드에도 동일한 제스처를 사용한다. 다른 컴퓨터의 실제 체감 성능은 해당 환경에서 후속 확인한다. 범위·동작·경계 조건·검증 방법에 중대한 모호성이 없다.
